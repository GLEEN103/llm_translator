# Chrome LLM Translator

웹페이지의 텍스트와 이미지 속 글자, YouTube 자막을 원하는 언어로 번역해 주는 Chrome 확장 프로그램입니다. 번역 결과를 원래 페이지 위에 표시해, 내용을 읽거나 영상을 보면서 바로 확인할 수 있습니다.

**번역은 외부 LLM API(Google AI Studio 또는 OpenAI)를 호출해 처리합니다.** 사용자가 발급한 API 키가 필요하며, 번역할 텍스트·이미지 픽셀·자막 텍스트가 선택한 공급자에게 전송됩니다. 화면에서 내용을 수집하고 결과를 표시하는 작업은 기기에서 처리합니다. API 사용료가 발생할 수 있습니다.

**[설치 및 초기 설정 안내 →](guide/installation.md)**

## 주요 기능

| 기능 | 사용 방법 |
| --- | --- |
| 페이지 본문 번역 | 확장 아이콘에서 **페이지 본문 번역**을 실행합니다. 페이지 구조를 유지하면서 텍스트를 바꾸고, 번역본을 ON/OFF로 전환합니다. |
| 선택한 텍스트 번역 | 텍스트 선택 → 우클릭 → **선택한 텍스트 번역**. 선택 영역 위에 번역 결과를 표시합니다. |
| 이미지 번역 | 이미지 우클릭 → **이미지 번역**. 멀티모달 모델이 이미지 속 글자를 인식·번역하고 이미지 위에 결과를 표시합니다. |
| YouTube 자막 번역 | 영상의 **자막 번역** 버튼에서 원문 자막과 목표 언어를 선택합니다. 번역을 ON으로 켜면 영상 시간에 맞춰 번역 자막을 표시합니다. 자막이 제공되는 Shorts도 지원합니다. |
| 토큰 사용 통계 | 확장 팝업에서 오늘의 입력·출력·전체 토큰을 확인하고, 별도 통계 화면에서 기간·공급자·모델·기능별 사용량을 조회합니다. |

YouTube 자막의 글씨 크기·서체·불투명도·위치를 조절할 수 있습니다. 설정 패널만 닫거나 패널과 자막을 함께 숨길 수도 있습니다. 최근 최대 **30개 영상**의 성공한 번역은 기기에 보관해 같은 모델·언어·원문으로 다시 볼 때 재사용합니다. 저장 용량은 최대 4 MiB이며 한도를 넘으면 오래 사용하지 않은 영상부터 정리합니다.


## 지원 API와 실행 환경

- **Google AI Studio**, **OpenAI (GPT)**를 지원합니다. 설정에서 API 키로 모델 목록을 불러오고 카드에서 선택합니다. 이미지 번역에는 이미지 입력을 지원하는 모델이 필요합니다.
- API 키는 **공급자·모델별로 이 브라우저에 저장**됩니다. 저장한 모델 사이를 전환할 수 있습니다.
- **kie.ai는 현재 사용 중지 상태**이며 선택할 수 없습니다.
- 데스크톱 **Chrome 116 이상**에서 압축해제된 확장으로 설치합니다.

## 데이터와 사용 범위

번역할 내용의 외부 전송 동의는 설치·업데이트된 확장 버전마다 최초 1회 받습니다. 이미지 번역은 이미지 픽셀을 보내며, YouTube 번역은 제공되는 자막 텍스트를 보냅니다. **영상·음성을 업로드하거나 음성을 직접 인식하는 기능은 아닙니다.** 자막이 없거나 읽을 수 없는 영상, 라이브·임베드 영상은 지원하지 않습니다.

API 키는 일반 웹페이지에 노출하지 않으며 다른 기기로 동기화하지 않습니다. 다만 브라우저 로컬 저장소는 암호화 금고가 아닙니다. 키 관리 방법은 [설치 및 API 설정 안내](guide/installation.md)를 참고하세요.
