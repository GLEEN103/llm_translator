# Chrome LLM Translator

화면 입력·출력은 기기에서 처리하고, 텍스트·이미지·자막 번역은 Google AI Studio 또는 OpenAI API로 처리하는 **확장 단독 실행 프로그램**이다. 사용자가 확장 설정에서 API 키를 입력하고 모델 카드에서 선택한다. kie.ai는 응답 불안정으로 레거시 보존하며 현재 선택·사용할 수 없다. 로컬 서버·연결 토큰·Node.js는 프로그램 사용에 필요 없다.

## 시작하기

**0.18.0 — 형식 오류 재시도·영상 번역 보관:** 응답 형식이 잘못되면 최초 요청 후 최대 **3회** 재시도한다. 끝내 실패한 묶음은 오류 로그와 함께 제외하고 자막은 **ON을 유지**한다. **실패 구간 재시도**로 해당 구간만 다시 실행할 수 있다. 최근 최대 **30개 영상**의 성공 번역은 같은 영상·모델·언어·원문일 때 재사용한다. 캐시는 기기에 최대 **4 MiB** 보관하며 API 설정의 **저장된 영상 번역**에서 확인·삭제한다. 확장과 열린 페이지를 새로고침하고 이번 버전의 동의를 완료한다. [구현·검증](docs/implementation-plans/0032-format-retries-and-video-history.md).

**0.17.0 — 묶음 병렬 번역:** 본문·부분·YouTube 자막은 최대 5개 묶음을 동시에 보내고, 해당 묶음들이 끝난 뒤 다음 차례까지 5초 쉽니다. 모든 탭·번역 공급자·이미지·재시도를 합쳐 최근 60초간 최대 60회로 제한합니다. 본문·부분·자막은 로컬 요청 한도에 도달하면 자동으로 기다렸다가 이어갑니다. 확장과 열린 페이지를 새로고침하고 이번 버전의 전송 동의를 완료하세요. [구현과 검증](docs/implementation-plans/0031-parallel-translation-batches.md).

**0.16.0 — OpenAI 직접 연동:** 확장과 열린 페이지를 새로고침한 뒤 **API 설정 → OpenAI (GPT) → API 키 입력 → 모델 목록 불러오기 → 카드 선택 → 선택 모델에 키 저장**을 진행한다. 이번 버전의 전송 동의 후 텍스트·이미지·YouTube 자막을 기존 UI로 번역한다. 키는 공급자·정확한 모델별로 보존하며 입력·출력·추론·전체 토큰을 기존 오늘 요약/통계에 집계한다. ChatGPT 구독과 OpenAI API 요금은 별도다. 계정의 모델 목록 중 이 확장이 지원하는 GPT 모델만 표시한다. [지원 모델·전송 구조·검증](docs/implementation-plans/0030-openai-direct-api.md).

**kie.ai 상태:** 0.15.2부터 선택·저장·재활성화·모델/가격 조회·번역 요청을 중지했다. 기존 Kie 키와 통계는 보존하며 API 설정의 **kie.ai 레거시 저장 키**에서 개별 삭제할 수 있다. 기존 활성 모델이 Kie이면 다른 공급자로 자동 전환하지 않는다. Google 또는 OpenAI 모델을 직접 저장/활성화한다. 아래 Kie 지원 설명은 이전 버전의 기록이다. [비활성화 계획·결과](docs/implementation-plans/0029-kie-legacy-disabled.md).

0.15.1은 Kie 요청을 보내기도 전에 **확장 연결 중단**으로 표시되던 초기화 오류를 수정했다. 실제 Chrome에서 정상 offscreen 포트에 `sender.documentId`가 생략되어 기존 검사가 연결을 거절한 것이 원인이었다. 생성마다 새 식별자를 부여하고 실제 숨김 문서와 대조하도록 수정했다. 격리된 Chrome에서 초기 연결·45초 지연 응답·문서 재생성을 확인했다. 업데이트 후 확장과 YouTube 페이지를 새로고침한다. [재현·수정 기록](docs/troubleshooting/2026-09-07-kie-offscreen-port.md).

0.15.0은 Kie 번역 대기를 **25초 → 180초**, 자막·본문 UI 대기를 **29초 → 190초**로 늘렸다. Chrome 서비스 워커의 긴 fetch 제약을 피하기 위해 Kie 통신을 확장 내부 offscreen 전용 Worker로 옮겼다. **Chrome 116 이상·offscreen 권한**이 필요하다. 키 저장·동의·예산·사용량 검사는 background에 유지하고 작업 종료 시 숨김 문서와 Worker를 정리한다. 로컬 서버는 필요 없다. [원인·수정·검증](docs/implementation-plans/0027-kie-long-response.md).

0.14.2는 kie.ai 번역의 JSON 코드블록과 Gemini 3.8 고유 텍스트 응답 형식을 처리하고, 실패 시 JSON/구조/구간 ID 등의 고정 오류 코드를 표시한다. 실제 보고된 응답은 확인하지 않았으며 모의 재현으로 호환성을 검증했다. [오류 추적과 재발 시 조치](docs/troubleshooting/2026-09-07-kie-gemini-response-format.md).

0.14.1은 kie.ai 모델명 오른쪽에 입력·출력 가격을 나란히 배치해 카드 높이를 줄였다. 입력은 파란색, 출력은 보라색이며 문구로도 구분한다. 좁은 화면에서는 카드가 한 열로 바뀌고 이름·ID가 줄바꿈된다. [카드 배치·좁은 화면 검증](docs/implementation-plans/0023-compact-model-price-layout.md).

0.14.0은 kie.ai 지원 Chat 모델을 **34개**로 확대하고 모델 카드에 **입력·출력 USD / 100만 토큰**을 표시한다. 가격에 마우스를 올리면 크레딧과 조회 시각을 확인한다. 공식 가격 화면의 크레딧·달러 환산값을 조회하므로 가격이나 할인율을 코드에 고정하지 않는다. kie.ai 설정을 보는 동안 5분마다 갱신하며 **가격 새로고침**도 제공한다. 실패·오래된 값·단위 미확인은 별도로 표시한다. [가격·모델 추가와 검증](docs/implementation-plans/0022-kie-live-pricing-and-chat-models.md).

0.13.0은 **kie.ai 텍스트·YouTube 자막 번역**과 계열별 모델 카드·검색·필터를 추가했다. 초기 지원은 Gemini/GPT/Claude 계열 10개 모델이며 공식 문서 목록과 교집합을 표시한다. 공급자·모델별 키와 통계를 분리한다. 토큰은 **10K, 3.4M**처럼 표시하며 마우스를 올리면 정확한 수치를 확인한다. 통계에는 공급자 필터도 제공한다. [지원 범위·검증 결과](docs/implementation-plans/0021-kie-provider-and-model-browser.md).

업데이트 후 확장과 번역할 페이지를 새로고침한다. Chrome이 새 `api.kie.ai`·`docs.kie.ai` 권한을 안내하면 확인하고 이번 버전의 전송 동의에 최초 1회 동의한다. 기존 Google 키는 유지된다.

0.12.0부터 확장 아이콘을 누르면 **오늘 사용한 입력·출력·전체 토큰**을 표시한다. **사용 통계 보기** 또는 API 설정의 **토큰 사용 통계 열기**에서 별도 통계 페이지를 연다. 오늘/7일/30일/전체 보관기간과 모델·번역 기능으로 필터링하고 일별·모델별 합계를 확인한다. 적용 이후 이 브라우저의 기록만 집계하며 최근 365일(최대 10,000개 집계)을 보관한다. API 응답에서 확인하지 못한 사용량은 미확인으로 표시한다. [통계 구현·검증](docs/implementation-plans/0020-token-usage-statistics.md).

1. Chrome 확장 관리 화면의 개발자 모드에서 `src/extension` 폴더를 압축해제된 확장으로 로드한다. 기존 설치라면 확장을 새로고침한다.
2. 확장의 **API 설정**에서 Google AI Studio 또는 OpenAI (GPT)를 선택하고 해당 공급자의 키를 입력한다. **모델 목록 불러오기 → 검색·계열 필터로 모델 카드 선택 → 선택 모델에 키 저장**을 진행한다. 확인된 출시일 최근순이며 미확인 날짜는 마지막이다. OpenAI는 계정의 API 목록 중 검증된 번역 지원 모델만 표시한다.
3. 팝업이나 설정 화면에서 원문 전송에 동의한다. 설치·업데이트된 버전마다 최초 1회만 받는다.
4. 부분 번역은 **텍스트 선택 → 우클릭 → 선택한 텍스트 번역**으로 즉시 실행하고 원문 위 오버레이에 표시한다. 본문 번역은 **확장 버튼 → 페이지 본문 번역**에서 원문 확인 후 **번역 시작**을 누른다.
5. 이미지 입력을 지원하는 Google 또는 OpenAI 모델을 활성화한 뒤 **이미지 우클릭 → 이미지 번역**을 누른다. 멀티모달 모델이 이미지 속 문자를 인식·번역하고 원본 이미지 위에 결과를 표시한다. 오버레이에서 목표 언어 변경·인식 원문 확인·재시도·닫기를 제공한다.
6. YouTube 일반 시청 페이지에서 **좋아요·싫어요 묶음 옆의 자막 번역**을 누른다. 기존 **확장 버튼 → YouTube 자막 번역**도 사용할 수 있다. 원문 자막(제작자/자동 생성)·목표 언어를 선택하고 **번역 ON**으로 켠다. ON 동안 새 구간을 자동 확인하여 미번역 문장만 번역하고 영상 시간에 맞춰 표시한다. **번역 OFF**는 자동 요청을 멈추고 자막을 숨긴다. **자막 세부 설정**에서 배경·글자 불투명도, 서체, 글씨 크기, 세로 위치, 가로 정렬을 조절하며 설정은 이 브라우저에 저장된다. **접기** 후에도 ON은 유지되며 페이지 버튼을 다시 누르면 설정을 펼친다.

본문은 기존 태그·스타일을 유지하며 텍스트만 교체한다. **번역본 ON/OFF**로 추가 API 호출 없이 전환하며 **패널 닫기** 후에도 결과는 유지하고 작은 **본문 번역 열기** 버튼으로 다시 연다. 같은 탭의 마지막 페이지 결과는 임시 저장해 새로고침 후에도 같은 URL·모델 설정·언어·원문이면 재사용한다. 탭 종료·브라우저 재시작·확장 재로드 시 삭제한다. 여러 요소는 최대 64구간·12,000자씩 하나의 구조화 요청으로 보내며 응답 ID로 원래 요소에 연결한다.

키는 공급자·모델별로 이 브라우저에 저장하여 재시작·업데이트 후 유지한다. **저장된 모델별 API 키**에서 모델을 골라 **저장 모델 사용**을 누르면 재입력 없이 전환한다. 개별·전체 삭제를 제공한다. 목록 조회는 모델 정보만 요청하고 저장·모델 전환은 API를 호출하지 않는다.

키를 동기화하거나 재표시하지 않는다. 다만 브라우저 로컬 저장소는 암호화 금고가 아니다. [API 키 보안 정책](docs/architecture/security.md)에 저장·접근·삭제·노출 대응과 보호 한계를 명시했다. 출시일을 확인하지 못한 모델은 목록 뒤에 표시한다.

이미지 수집·축소·재인코딩은 기기에서 처리하며 인식·번역은 활성 Google 또는 OpenAI API로 처리한다. 픽셀 읽기가 차단되면 기기에서 화면의 이미지 사각형만 잘라 사용한다. 이 경우 이미지 전체가 화면 안에 보여야 하며 가림·변형 등을 확인할 수 없으면 안내한다. 이미지 URL·전체 화면은 모델에 보내지 않고 이미지 결과는 오버레이 종료 때 삭제한다.

YouTube 자막 텍스트만 활성 Google 또는 OpenAI에 보내며 영상·음성·URL·타임코드는 보내지 않는다. 아직 번역되지 않은 구간은 준비 중으로 안내하고 이전 자막을 남기지 않는다. 자막이 없거나 YouTube가 자막 접근을 제한하면 안내한다. Shorts의 제공되는 자막도 지원한다. 임베드·라이브·PIP 자막은 현재 제외한다. 결과는 오버레이 종료/영상 이동 때 삭제한다.

0.9.0은 연속 자막 확인과 표시 설정을 추가했다. 자막 재수집은 완료 후 최소 10초 간격이며 일시적 실패는 자동 재시도한다. OFF 후 ON에서는 완료 문장을 재사용하지만 탭 종료·영상 이동은 삭제한다. 직접 자막 요청이 비어 있으면 정상 플레이어 응답을 사용하며 수집 중 YouTube 원문 자막이 잠시 켜지거나 선택 언어로 변경될 수 있다. 업데이트 후 확장과 YouTube 페이지를 모두 새로고침한다. [연속 번역 변경 기록](docs/troubleshooting/2026-09-06-continuous-captions-and-style.md).

자세한 내용은 [설치·사용 안내](docs/architecture/local-development.md)를 참고한다. OpenAI는 공식 API 직접 연동이다. kie.ai는 레거시로 비활성화했으며 Google 또는 OpenAI 모델을 사용한다.

0.10.0은 페이지 버튼 자동 표시를 위해 `https://www.youtube.com/*` 사이트 권한을 추가했다. 업데이트 후 Chrome이 새 권한을 안내하면 확인하고 확장·YouTube 페이지를 새로고침한다. 자동 탐지는 버튼만 표시하며 번역을 시작하지 않는다. 키/동의가 없으면 버튼에서 확장 설정으로 안내한다. 좋아요 구조를 찾지 못하면 같은 작업 버튼 영역 끝에 표시하며, 영역이 없는 레이아웃에서는 기존 확장 버튼을 이용한다.

0.11.3은 **닫기**로 자막 설정 패널 전체를 숨기고, **패널·자막 숨기기**로 영상 위 확장 UI를 모두 숨긴다. 번역 ON과 결과는 유지하며 페이지 번역 버튼이나 확장 팝업으로 복원한다. 기존 종료 버튼은 제거했다. 번역을 멈추려면 **번역 OFF**를 사용한다. 같은 영상의 페이지 버튼은 설정 UI를 열기/숨기기로 토글한다. 최초 진입은 즉시 주입하고, 무응답 대기를 제한하며, 화면 밖에 있는 영상은 UI와 함께 화면 안으로 이동한다. Shorts에서는 영상 오른쪽 작업 영역의 **번역** 버튼을 사용한다. 다음 Shorts로 이동하면 이전 작업을 종료하고 새 영상은 OFF로 시작한다. [재생 직후 UI 소실 수정과 검증](docs/implementation-plans/0019-playback-start-panel-lifecycle.md).

## 개발 검증

0.10.2는 페이지 자막 버튼의 다크/라이트 글자색과 인접 버튼 높이·서체를 맞춘다. YouTube 홈/다른 영상에서 이동한 경우의 클릭·후속 자막 요청 검증을 보완하고, 열기 응답이 없으면 20초 후 버튼을 다시 활성화한다. [버튼 수정 기록](docs/troubleshooting/2026-09-06-launcher-theme-size-click.md).

0.10.1은 YouTube 원문 자막 OFF 상태의 첫 실행과 재시도 복구를 개선했다. 트랙 준비를 기다리고 무응답이면 자막 모듈만 한 번 재초기화한다. 최초 목록 읽기에 실패한 경우 페이지의 **자막 번역** 버튼을 다시 누르면 목록을 다시 읽는다. 오류가 날 때마다 페이지를 새로고침할 필요는 없다. [복구 수정 기록](docs/troubleshooting/2026-09-06-caption-cold-start.md).

개발 테스트에만 Node.js 22 이상을 사용한다. 외부 npm 패키지와 빌드는 필요 없다.

0.18.0은 자동 테스트 **270개**, JavaScript **78개** 구문·설정 검사와 보안 하네스를 통과했다. 격리 Chrome 152에서 가짜 응답으로 형식 재시도/오류 로그/자막 ON 유지/실패 구간 복구/캐시 재진입을 확인했고, 재진입 시 추가 API 요청은 0회였다. 본문 5개 병렬 처리·전체 취소와 360px 자막 패널 표시도 통과했다. 실제 API 호출은 하지 않았다.

0.15.2의 레거시 사용 중지 회귀를 포함한 자동 테스트 220개, JavaScript 65개 구문·설정 검사와 보안 하네스를 통과했다. 이번 변경은 가짜 키·모의 네트워크로 검증했으며 실제 Chrome UI 조작이나 유료 API 호출은 하지 않았다.

```powershell
npm test
npm run check
powershell -NoProfile -ExecutionPolicy RemoteSigned -File tools/verify-harness.ps1
```

번역 검증은 가짜 키·모의 응답을 사용한다. 0.15.1 자동 테스트 219개와 JavaScript 65개 구문·설정 검사, 보안 하네스를 통과했다. 가상 시간에서 취소·180초 종료·포트 검증·정리를 확인했다. 추가로 격리된 실제 Chrome 152에서 서비스 워커에 디버거를 붙이지 않고 초기 연결·45초 응답 대기·offscreen 종료 후 재생성을 검증했다. 네트워크만 모의하며 실제 Google/kie.ai 키로 번역하는 전체 통합 검증은 하지 않았다. 공식 공개 목록·가격은 인증 없이 읽기 검증했다.
