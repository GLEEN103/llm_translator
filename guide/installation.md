# 설치 및 초기 설정

[프로그램 소개로 돌아가기](../README.md)

이 안내는 **0.18.0** 기준입니다. Chrome 확장을 설치한 뒤 본인의 Google AI Studio 또는 OpenAI API 키를 등록하면 사용할 수 있습니다. 번역은 외부 API가 처리하며, 선택한 콘텐츠가 공급자에게 전송되고 API 사용료가 발생할 수 있습니다.

## 1. 준비하기

- 데스크톱 **Chrome 116 이상**
- 이 저장소의 파일
- Google AI Studio 또는 OpenAI에서 발급한 API 키와 해당 모델의 API 사용 권한

프로그램 사용에는 Node.js 설치, npm 명령 실행, 빌드, 로컬 서버가 필요하지 않습니다. ChatGPT 구독과 OpenAI API 사용 요금은 별도입니다. 모바일 Chrome의 확장 설치·실행은 지원 대상으로 검증하지 않았습니다.

## 2. 확장 설치하기

1. [GitHub 저장소](https://github.com/GLEEN103/llm_translator)에서 **Code → Download ZIP**을 누르고, 내려받은 ZIP 파일을 원하는 위치에 압축 해제합니다. Git을 사용한다면 저장소를 복제해도 됩니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 압축 해제한 폴더 안의 **`src/extension`** 폴더를 선택합니다. 저장소 최상위 폴더가 아니라 `manifest.json`이 들어 있는 폴더입니다.
6. 확장 목록에 **Local LLM Translator**가 나타나는지 확인합니다. Chrome 도구 모음의 확장 프로그램 메뉴에서 고정하면 쉽게 열 수 있습니다.

예를 들어 ZIP을 `llm_translator-main` 폴더에 풀었다면 `llm_translator-main/src/extension`을 선택합니다. Chrome이 이 폴더에서 확장 파일을 읽으므로 설치 후 폴더를 삭제하거나 이동하지 마세요.

## 3. API 키와 모델 설정하기

1. 확장 아이콘 → **API 설정**을 엽니다.
2. **번역 공급자**에서 **Google AI Studio** 또는 **OpenAI (GPT)**를 선택합니다. kie.ai는 사용 중지 상태입니다.
3. **API 키**를 입력하고 **모델 목록 불러오기**를 누릅니다. 이때 선택한 공급자에게 API 키를 보내 사용 가능한 모델 목록을 조회합니다.
4. 표시된 모델 카드에서 사용할 모델을 선택합니다. 모델 이름을 직접 입력할 필요는 없습니다. 검색·계열 필터로 찾을 수 있으며 확장에서 지원하는 모델만 표시됩니다.
5. **선택 모델에 키 저장**을 누릅니다. 해당 공급자·모델의 키가 저장되고 활성화됩니다. 이미지 번역을 사용하려면 이미지 입력을 지원하는 모델을 선택하세요.
6. 팝업 또는 설정의 **텍스트·이미지·자막 전송 동의** 내용을 확인한 뒤 **동의하고 계속**을 누릅니다. 같은 확장 버전에서는 최초 1회만 받습니다.

키는 브라우저를 다시 열어도 유지됩니다. 다른 모델에도 키를 저장하려면 **새 모델 추가**부터 같은 절차를 진행하세요. 이미 저장한 모델로 전환할 때는 **저장된 모델별 API 키**에서 모델을 고르고 **저장 모델 사용**을 누릅니다. 카드나 공급자 선택만 바꿔서는 활성 모델이 바뀌지 않습니다.

공용 기기에 키를 저장하지 마세요. 키는 공급자·모델별로 이 브라우저에 저장되며 재표시하거나 다른 기기에 동기화하지 않습니다. 브라우저 저장소는 암호화 금고가 아닙니다. 설정에서 선택 모델 또는 모든 모델의 키를 삭제할 수 있습니다. 키가 노출되었다면 공급자에서 폐기·재발급하세요. 확장에서 삭제하는 것만으로 공급자의 키가 폐기되지는 않습니다.

## 4. 첫 번역 실행하기

설치 전에 열어 둔 페이지라면 먼저 새로고침합니다. 짧고 민감하지 않은 내용으로 동작을 확인하세요.

### 텍스트와 이미지

- **부분 번역:** 텍스트를 선택한 뒤 우클릭 → **선택한 텍스트 번역**. 선택 영역 위에 결과가 표시됩니다.
- **본문 번역:** 확장 아이콘 → **페이지 본문 번역** → 원문·목표 언어 확인 → **번역 시작**. 완료 후 **번역본 ON/OFF**로 원문과 번역문을 전환합니다.
- **이미지 번역:** 이미지 우클릭 → **이미지 번역**. 이미지 위의 오버레이에서 인식·번역 결과와 목표 언어를 확인합니다.

### YouTube 자막

1. 자막이 제공되는 YouTube 영상을 엽니다.
2. 좋아요 버튼 옆의 **자막 번역**을 누릅니다. Shorts에서는 오른쪽 작업 영역의 **번역**을 누릅니다. 버튼이 보이지 않으면 확장 아이콘 → **YouTube 자막 번역**으로 엽니다.
3. **원문 자막**과 **목표 언어**를 고릅니다.
4. **번역 OFF**를 눌러 **번역 ON**으로 바꿉니다. ON 동안 새 자막을 확인하고 아직 번역하지 않은 구간을 자동으로 요청합니다. 초기 번역 준비에는 시간이 걸릴 수 있습니다.
5. **자막 세부 설정**에서 글씨 크기·서체·불투명도·위치를 조절합니다.

**닫기**는 설정 패널만 숨기며 자막 번역을 유지합니다. **패널·자막 숨기기**는 둘 다 숨깁니다. 페이지의 **자막 번역** 버튼은 설정 UI 표시를 켜고 끄는 토글이고, 확장 팝업에서는 UI를 다시 열 수 있습니다. 번역 요청 자체를 중단하려면 **번역 ON**을 눌러 OFF로 바꾸세요.

새로고침하거나 다른 영상으로 이동하면 번역은 OFF에서 시작합니다. 다시 ON으로 켜면 현재 자막을 읽은 뒤 저장된 번역부터 확인하고, 같은 영상·공급자·모델·언어·원문에 해당하는 성공 번역을 재사용합니다. 저장되지 않은 부분만 새로 번역합니다. **API 설정 → 저장된 영상 번역**에서 보관 현황과 전체 삭제를 제공합니다.

자막 없는 영상의 음성을 직접 인식하지 않으며, 라이브·임베드·읽기 제한이 있는 영상은 지원하지 않습니다.

### 사용량 확인

확장 아이콘에서 오늘 사용한 토큰을 확인합니다. **사용 통계 보기** 또는 API 설정의 **토큰 사용 통계 열기**로 기간·공급자·모델·기능별 기록을 확인할 수 있습니다. 이 브라우저에서 확인한 API 응답의 사용량이며, 계정 전체 사용량이나 청구 금액은 아닙니다.

## 5. 업데이트하기

1. 새 버전의 저장소 파일을 내려받아 설치에 사용한 폴더를 갱신합니다. Git으로 설치했다면 해당 폴더에서 변경사항을 확인한 뒤 갱신합니다.
2. `chrome://extensions`에서 **Local LLM Translator**의 새로고침 버튼을 누릅니다.
3. 번역할 웹페이지와 YouTube 페이지도 새로고침합니다.
4. 새 확장 버전의 전송 동의가 표시되면 내용을 확인하고 동의합니다.

같은 설치를 갱신하면 저장한 키·사용 통계·영상 번역 캐시는 유지됩니다. 업데이트하려고 확장을 삭제 후 재설치할 필요는 없습니다. 확장을 제거하면 브라우저에 보관한 설정과 기록도 삭제됩니다.

## 문제가 생겼을 때

| 증상 | 확인할 내용 |
| --- | --- |
| 확장을 로드할 수 없음 | ZIP을 압축 해제했는지, `manifest.json`이 있는 `src/extension`을 선택했는지 확인합니다. |
| 모델 목록이 비어 있거나 조회 실패 | 공급자에 맞는 키인지, 키의 API 권한과 공급자 상태를 확인합니다. 지원 목록 밖의 모델은 표시되지 않습니다. |
| 번역 버튼을 사용할 수 없음 | 모델 저장·활성화와 전송 동의를 완료했는지 확인합니다. Chrome 내부 페이지 등 확장이 접근할 수 없는 페이지는 번역할 수 없습니다. |
| YouTube 페이지 버튼이 보이지 않음 | Chrome의 확장 사이트 접근 설정에서 YouTube 접근을 확인하고 페이지를 새로고침합니다. 확장 팝업에서도 자막 UI를 열 수 있습니다. |
| 자막을 불러오지 못함 | 영상에 자막이 있는지 확인하고 **목록 새로고침**을 누릅니다. 일부 영상은 YouTube 접근 제한이나 플레이어 변경으로 읽을 수 없습니다. |
| 일부 자막이 번역 오류로 표시됨 | **번역 오류 로그**를 확인하고 **실패 구간 재시도**를 누릅니다. 형식 오류는 자동으로 최대 3회 재시도한 뒤 해당 묶음만 오류로 남깁니다. |

오류를 제보할 때는 재현 순서와 고정 오류 코드를 적어 주세요. API 키·인증 헤더·민감한 원문은 포함하지 마세요.
