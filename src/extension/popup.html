텍스트·이미지·자막 전송 동의

번역을 실행하면 선택한 텍스트·YouTube 자막 텍스트가 설정에서 선택한 Google AI Studio 또는 OpenAI로 전송됩니다. kie.ai는 레거시로 보존되어 현재 사용할 수 없습니다. 이미지 번역은 활성 공급자의 지원 모델로 이미지 픽셀을 전송합니다. 이미지 속 개인정보도 포함될 수 있으며 API 사용료가 발생할 수 있습니다. 이미지 수집·축소·필요한 화면 캡처와 이미지 영역 자르기, 결과 표시는 이 기기에서 처리합니다. 전체 화면·이미지 URL·영상 URL·타임코드·음성·영상은 모델에 보내지 않습니다.

부분 번역은 페이지에서 텍스트 선택 → 우클릭 → 선택한 텍스트 번역으로 실행합니다.

이미지에서 우클릭 → 이미지 번역을 누르면 인식·번역 결과를 이미지 위에 표시합니다. 이미지 입력을 지원하는 Google AI Studio 또는 OpenAI 모델을 활성화하세요.

부분·이미지 번역은 메뉴에서 바로 실행합니다. 본문은 원문 확인 후 실행하며 ON/OFF로 전환하고 탭 종료까지 결과를 보관합니다. 이미지 결과는 오버레이를 닫으면 삭제합니다. YouTube 자막은 팝업 또는 영상의 자막 번역 버튼에서 열고 원문 자막·목표 언어를 선택한 뒤 시작합니다. 닫기는 UI를 숨기며, 영상 이동·탭 종료 시 자막 결과를 삭제합니다.
