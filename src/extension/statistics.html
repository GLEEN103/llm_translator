기록 읽는 방법

토큰은 K(천)·M(백만)·B(십억)·T(조) 단위로 반올림합니다. 숫자에 마우스를 올리면 정확한 합계를 확인합니다. 숫자는 응답에서 확인된 합계입니다. *는 해당 항목을 알려주지 않은 요청이 포함됨을, —는 확인된 값이 없음을 뜻합니다. 미확인 요청은 진행 중·중단·실패 또는 입력/출력/전체 중 일부가 누락된 요청입니다. 미확인을 실제 사용량 0으로 보지 마세요.

추론 상세가 제공되면 출력에서 분리합니다. kie.ai가 추론 상세를 생략하면 출력에 추론이 포함될 수 있습니다. 캐시 입력은 입력에 포함되며 다시 더하지 않습니다. 전체 토큰은 API 보고값이며, Claude는 입력·캐시 생성/읽기·출력 보고값을 합산합니다. 자동 재시도는 별도 요청으로 기록하고 저장된 번역을 다시 표시하는 경우에는 더하지 않습니다.

기록 전 사용량·다른 기기의 사용량은 포함되지 않습니다. 청구금액이나 계정 전체 사용량은 해당 공급자에서 확인하세요. API 키·원문·이미지·영상 URL은 이 통계에 저장하지 않습니다.
