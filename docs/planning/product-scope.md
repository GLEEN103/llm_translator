# 제품 범위

## 확정 방향

- 0.18.0부터 응답 형식 오류를 최초 요청 후 최대 3회 재시도한다. 최종 실패는 해당 묶음만 오류로 남기며 자막 ON을 유지한다. 안전한 오류 로그와 실패 구간 수동 재시도를 제공한다. 최근 최대 30개 영상의 성공 번역을 기기에 최대 4 MiB 보관하고 같은 영상·공급자·모델·언어·원문에서 재사용한다. API 설정에서 현황 조회와 전체 삭제를 제공한다.
- 0.16.0부터 OpenAI 공식 API 직접 연동을 제공한다. API에서 받은 목록과 검증한 GPT 모델의 교집합을 카드로 선택하며 텍스트·이미지·YouTube 자막 번역 및 공급자별 사용 통계를 지원한다. 키는 기존 공급자·모델별 저장 정책을 따른다. ChatGPT 로그인/구독을 API 인증으로 사용하지 않는다.
- 0.15.2부터 kie.ai는 응답 불안정으로 레거시 보존한다. 현재 선택·신규 저장·재활성화·목록/가격 조회·번역 요청을 금지한다. 기존 키와 통계는 보존하며 키 삭제를 제공한다. 아래 Kie 지원 내용은 보존된 구현 범위를 설명하며 현재 사용 가능 상태를 의미하지 않는다.
- 화면 입력·결과 표시는 사용자 기기에서 처리하고 번역은 LLM API로 처리한다.
- 확장 설정 UI에서 사용자가 공급자별 API 키를 입력하고 불러온 모델 카드에서 검색·선택한다. Google은 API 목록, kie.ai는 공식 문서 목록과 구현한 지원 경로의 교집합을 사용한다. 확장 background가 공급자 API를 직접 호출한다.
- 원문 전송 동의는 설치·업데이트된 버전마다 최초 1회 받는다. 같은 버전의 반복 번역·재시도·브라우저 재시작에는 다시 묻지 않는다.
- 세부 모델은 확인된 출시일의 최근순으로 정렬한다. 날짜 미확인 모델은 마지막에 둔다.
- 키는 공급자·모델별로 영구 저장하며 저장 모델 활성화·개별/전체 삭제를 제공한다. 키가 없는 모델로 다른 키를 자동 복사하거나 전송하지 않는다.
- 로컬 서버는 계획과 제품 구성에서 제거한다. 기술적으로 꼭 필요한 상황이 확인되면 먼저 사용자에게 제약과 대안을 알린다.
- 텍스트를 먼저 구현했으며 0.7.0부터 멀티모달 이미지 인식·번역, 0.8.0부터 YouTube 일반 녹화 영상의 제작자/자동 생성 자막 번역을 지원한다.
- 현재 사용 가능한 공급자는 Google AI Studio와 OpenAI다. kie.ai는 레거시다.
- 동영상은 자막만 다룬다. 음성 인식·더빙·영상 업로드는 범위에 포함하지 않는다.

## 현재 구현

0.14.1은 모델 정보와 입출력 가격을 카드 상단 좌우로 묶고 입력 파랑/출력 보라색으로 표시한다. 좁은 디스플레이에서는 한 열 카드와 자연 줄바꿈으로 정보를 유지한다. 가격 데이터/갱신·키 관리·모델 지원 범위는 0.14.0과 같다. 최신 표시 변경은 [0023](../implementation-plans/0023-compact-model-price-layout.md)을 따른다.

0.14.0은 kie.ai Chat 모델을 34개로 확대했다. 새 GPT·Codex·Claude·Gemini·Grok 모델을 확인된 고정 경로에 연결한다. 모델 카드에 일반 입력·출력 USD/100만 토큰을 표시하며 공식 공개 가격의 크레딧·달러 환산값을 함께 사용한다. 설정 화면 진입·모델 조회·수동 갱신과 표시 중 5분 주기로 가격 변경을 반영한다. 가격 조회 실패는 번역을 막지 않으며 이전 조회값·미확인을 명시한다. 실제 청구액·지역/계정별 할인·과거 요청 금액 계산은 범위에 포함하지 않는다.

0.13.0은 kie.ai의 Gemini/GPT/Claude 초기 10개 모델에 텍스트·YouTube 자막 번역을 지원한다. 이미지 번역은 Google만 지원하며 kie.ai 선택 시 캡처·전송 전에 안내한다. 계열별 모델 카드·검색·필터·선택 요약과 공급자별 키 슬롯을 제공한다. 공식 출시일을 확인하지 못한 모델은 마지막에 둔다. 공개 문서 목록은 계정별 지원·키 유효성을 보장하지 않는다. 통계는 공급자별로 구분하고 K/M 단위 표시와 정확값 툴팁을 제공하며 원값을 보존한다.

0.12.0은 본문·부분 텍스트·이미지·자막 번역의 Google API 응답 토큰을 trusted local에 기록한다. 별도 통계 페이지에서 기간·모델·기능별 입력/출력/추론/전체와 일별·모델별 합계를 제공하고 확장 팝업에는 오늘 요약을 표시한다. 원문/키/URL을 통계에 남기지 않으며 과거 사용량 역조회·계정 전체 집계·금액 계산은 포함하지 않는다.

우클릭 즉시 원문 위에 표시하는 선택 번역 오버레이, 본문 텍스트 교체·ON/OFF·패널 축소, 탭 종료 전까지 본문 결과 임시 보관과 재사용, 본문 원문 미리보기·버전별 최초 동의, 언어 선택, 구조화 요청·ID 응답 연결, Google API 직접 호출, 진행·취소·부분 실패 재시도, API 키 설정·모델 목록을 구현했다.

이미지 우클릭 메뉴에서 멀티모달 인식과 목표 언어 번역을 한 번 요청하고 이미지 위 오버레이로 표시한다. 이미지 수집·처리는 온디바이스, 인식은 API로 수행하도록 사용자 요청을 반영했다. 온디바이스 OCR은 현재 구현 방식이 아니다.

YouTube 일반 시청 페이지에서는 팝업의 자막 번역 버튼으로 제작자/자동 생성 트랙·목표 언어를 선택한다. 타임코드는 기기에 남기고 텍스트를 구조화 일괄 번역하여 영상 시간에 맞춘 반투명 자막을 표시한다. 0.9.0부터 번역 ON 동안 새 구간을 주기적으로 수집·병합하고 미번역 문장만 자동 요청한다. OFF는 수집/번역을 중지하고 표시를 숨기며 같은 작업의 결과는 재사용한다. 접기·닫기와 전체화면/일시정지/탐색/배속을 처리한다. 배경/글자 불투명도, 기기 내 서체, 크기, 세로 위치, 가로 정렬, 미리보기·기본값 복원을 제공한다. 표시 설정만 trusted local에 저장하고 ON 상태·자막 결과는 작업 메모리에만 보관하며 오버레이 종료/영상 이동 시 삭제한다.

키는 trusted local 저장소에 모델별로 보관하며 일반 페이지와 content script에 전달하지 않는다. 조회 임시 키·카탈로그는 trusted session에만 둔다. 저장·모델 활성화는 API를 호출하지 않는다. 한국어를 기본 목표 언어로 제공하고 변경할 수 있다. 보안 정책과 한계는 [보안 문서](../architecture/security.md)를 따른다.

0.10.0부터 YouTube 영상의 좋아요·싫어요 묶음 옆 `자막 번역` 버튼을 자동 표시한다. 홈→영상 이동과 버튼 영역 교체에 대응한다. 정확한 www.youtube.com 사이트 권한만 추가하며 자동 탐지로 번역을 시작하지 않는다. 클릭은 기존 패널을 열고 같은 영상의 진행 상태를 유지한다. 키/동의 미설정은 확장 설정으로 안내한다.

0.11.0은 일반 영상과 Shorts에서 패널 전체 숨김과 패널·자막 모두 숨김을 제공한다. 숨김은 ON·결과를 유지하며 페이지 버튼/팝업으로 복원한다. Shorts는 현재 보이는 세로 영상과 제작자/자동자막에 연결하고 오른쪽 작업 영역에 번역 버튼을 둔다. 실제 다음 영상 ID/문서 변경은 이전 작업을 종료하며 새 영상 자동 ON은 하지 않는다.

## 후속 검증과 기능

- 실제 Chrome 설치·계정별 Google 모델 연동 및 번역 품질·지연 검증.
- 복잡한 사이트별 레이아웃·동적 페이지 대응.
- 추가 공급자의 직접 호출 가능 여부와 각 API 규격 검증.
- 이미지의 실제 모델별 인식 품질·복잡한 사이트와 화면 캡처 호환성, 실제 Chrome/YouTube 자막 수집 및 공급자 통합 검증. 임베드·라이브·다른 영상 플랫폼은 후속 범위.
- 금액 기준 비용 관리와 배포 방식.

현행 기준은 [전체 계획](../implementation-plans/0002-text-first-translation-roadmap.md), 최신 변경은 [0022 — kie.ai 가격 갱신·Chat 모델 추가](../implementation-plans/0022-kie-live-pricing-and-chat-models.md)에서 관리한다. 이전 번호 계획은 해당 버전의 기록이다. 실제 Google/kie.ai 계정 호출·번역 품질·지연은 후속 검증 대상이다.

0.11.1에서 자막 설정 패널의 기존 종료용 닫기를 제거하고 UI 숨기기를 닫기로 변경했다. 같은 영상의 페이지 버튼은 기존 패널을 즉시 복원하며 ON/언어/결과를 유지한다. 번역 중지는 OFF, 결과 정리는 영상 이동·문서 종료에서 수행한다.

0.11.2부터 페이지 자막 번역 버튼은 설정 UI 표시 토글이다. 번역 ON/OFF와 독립적이며 같은 작업 결과를 유지한다. 최초 열기 로딩 대기/화면 밖 배치/초기화 실패 복구를 보완했다.

0.11.3의 설정 패널 수명은 현재 문서/영상 ID 기준이다. 같은 영상의 노드 교체/0 크기/일시 부재는 패널을 종료하지 않는다. 안정화 전에는 준비 안내와 가시 대체 위치를 사용하고 자막/새 요청만 일시 정지한다. 실제 영상 ID 변경은 이전 작업을 종료한다.
