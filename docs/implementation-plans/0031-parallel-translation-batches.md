# 0031 번역 묶음 병렬 처리와 공통 요청 제한

## 목적과 범위

- 본문·부분·YouTube 자막 번역을 최대 5개 구조화 묶음씩 동시에 요청한다. 묶음당 64구간·12,000자 제한은 유지한다.
- 한 차례 요청들의 처리가 끝나면 다음 차례까지 5초 대기한다. 최근 60초간 API 시도는 모든 탭·공급자·이미지가 공유하는 background 제한으로 최대 60회를 보장한다. Google 재시도도 포함한다.
- 로컬 동시 작업/분당 제한은 전송 전 대기로 처리한다. 실제 공급자의 시간 초과·연결 단절을 안전하지 않게 자동 재전송하지 않는다.
- 취소·OFF·설정 변경은 진행 중인 모든 작업을 취소한다. 응답 순서와 관계없이 ID로 결과를 적용하고 이전 세대의 늦은 응답은 버린다.

## 변경 대상과 설계

- `core.js`, `content.js`: 최대 5개 병렬 실행, 차례 사이 대기, 로컬 한도 대기 및 취소 확인. 작업별 고유 ID와 진행 중 ID 집합.
- `video-core.js`, `video-session.js`: 재생 위치 우선으로 최대 5개 묶음 선택, 각 완료 시 캐시 반영, 모든 작업 완료 후 다음 차례 예약. OFF 시 전체 취소.
- `contract.mjs`, `broker.mjs`: 공통 동시 5개/이동 구간 60회 제한. trusted session의 시도 시각을 유지하여 서비스 워커 재시작으로 제한을 초기화하지 않는다.
- `openai-offscreen-host.mjs`: 검증된 작업 Worker 최대 5개. Kie 레거시는 비활성 상태 유지.
- manifest·보안 정책·하네스 및 관련 문서 갱신.

## 보안 영향

- API 키 취급, 전송 동의, URL/원문 전송 범위는 변경하지 않는다. 병렬화로 순간 사용량은 증가하지만 기존 문자 예산과 새 공통 요청 제한을 모두 적용한다.
- 장시간 대기는 content의 작업 사이에서 수행하여 기존 API 응답 제한시간과 Chrome 서비스 워커 수명에 대기 시간을 더하지 않는다.
- 실제 API 호출이나 실제 키 열람 없이 가짜 응답으로 검증한다.

## 검증 방법

- 동시 5개 시작/6번째 대기, 5초 휴식, 순서가 바뀐 응답, 전체 취소 및 늦은 응답 무시, 일부 실패와 성공 캐시 보존을 테스트한다.
- 공통 60회 경계·60초 만료·서비스 워커 재생성·경합 시 한도 우회 방지와 Google 재시도 산입을 검증한다.
- OpenAI 실제 Worker 호스트의 5개 병렬 작업 지원을 모의 전송 테스트로 확인한다.
- 이미 허가된 격리 Chrome 프로필에서 가짜 응답으로 실제 offscreen Worker 5개 병렬 전송과 정리를 확인한다.
- 같은 격리 Chrome에서 실제 content/DOM 코드에 모의 runtime만 연결하여 본문 400구간의 병렬 적용·5초 대기·ON/OFF·취소를 확인한다.
- 전체 테스트, `node tools/check.mjs`, 하네스 검증을 수행한다.

## 구현 결과

- 버전 0.17.0, 보안 정책 schema17. 본문·부분·자막의 최대 5개 병렬 처리/5초 휴식, 공통 이동 구간 60회 제한, 로컬 한도 자동 대기와 전체 취소를 구현했다. 묶음당 64구간/12,000자와 세션 문자 예산은 유지한다.
- `node --test tools/tests/*.test.mjs`: **255개 통과**. 5개 동시 시작/6번째 제한, 역순 응답, 일부 로컬 실패와 캐시 보존, 중단/늦은 응답, 60회 경계/슬롯 경합/다중 탭/워커 재생성/Google 재시도 산입을 확인했다.
- `node tools/check.mjs`: **JavaScript 75개 및 JSON·권한 검사 통과**. 보안 하네스도 통과했다.
- 실제 격리 Chrome **152.0.7977.77**에서 가짜 OpenAI 응답 5개가 동일 offscreen 문서의 Worker들로 처리되고 완료 뒤 문서가 정리됨을 확인했다. 실제 공급자 요청과 실제 키 열람은 하지 않았다.
- 실제 content/DOM 코드 + 모의 runtime에서 본문 **400구간 → 7개 묶음**, 최대 동시 **5개**, 첫 차례 완료와 다음 차례 시작 사이 **5,020.5ms**를 확인했다. 결과 ID 연결, 추가 요청 없는 ON/OFF, **5개 전체 취소**와 늦은 응답 무시가 통과했다. 테스트 페이지의 누락된 UTF-8 선언은 fixture에서 수정했다.
- Chrome 결과: `tools/.tmp/openai-smoke-1788716255123/result.json`. 첫 샌드박스 Chrome 시도는 탭 충돌로 실패했고, 기존 허가 범위의 격리 실행에서 검증을 완료했다. 실행한 전용 브라우저는 종료했다.
- 실제 공급자 모델/계정의 5개 동시 호출 지연과 공급자 자체의 RPM/TPM 한도는 모의 응답으로 검증할 수 없다. 확장의 60회 제한은 번역 시도 예약에 적용하며 모델 목록·YouTube 자막 수집은 포함하지 않는다. 로컬 한도 대기는 보수적으로 최대 60초 후 재확인하고 API 오류의 기존 중단 정책을 유지한다.
