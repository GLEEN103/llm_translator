# 0015 — 페이지 자막 버튼 테마·크기·클릭 (0.10.2)

## 확인과 계획 (코드 변경 전)

첨부 화면에서 자막 버튼 글자가 검고 주변보다 작다. 기존 코드의 CSS 변수 미정의 시 검정 fallback, 고정 36px/14px가 원인 경로다. 클릭 경로는 SPA에서 현재 주소와 sender의 문서 주소가 다르면 거절하는 분기를 확인한다. 실제 사용자 환경의 클릭 실패 원인 확정과 모의 재현은 구분한다.

- html/body dark 상태를 읽어 명시적 글자/배경 색을 적용하고 테마 변경을 감지한다. 인접 좋아요/공유 버튼의 계산된 높이·서체·글씨 크기·굵기를 맞춘다. 기존 버튼 노드/이벤트는 변경하지 않는다.
- 실제 클릭/키보드 활성화를 보존하고 클릭의 상위 페이지 전파를 차단한다. 열기 응답 시간 초과 뒤 비활성 상태를 해제하고 재시도 안내한다.
- inline 진입은 sender의 정확한 YouTube 출처·메인 프레임·documentId를 확인하되 현재 영상은 tabs.get의 현재 URL 및 고정 documentId에서 읽은 location.href로 판정한다. SPA 초기 홈/이전 watch sender URL 때문에 유효한 클릭을 거절하지 않는다. 임의 메시지 탭/URL을 사용하지 않으며 변경된 문서/외부 출처는 계속 거절한다.
- 버전 0.10.2. 권한·전송 동의·키/서버 정책 유지.
- 후속 자막 목록/번역 요청의 assertVideo에도 같은 출처·현재 탭 영상·문서 grant 검증을 적용해 패널만 열리고 다음 단계가 오래된 sender URL로 실패하는 경로를 함께 수정한다.

## 검증

broker 회귀: 홈/이전 영상 sender URL + 현재 영상 문서 성공, 다른 출처/프레임/문서/영상 거절. 브라우저 fixture: dark/light 전환, 인접 높이/폰트 비교, 실제 마우스·키보드 패널 열기, ON 유지, 기존 DOM 회귀. 자동 테스트·구문·하네스 후 문서 반영. 실제 키/API는 사용하지 않는다.

## 결과

- 0.10.2 구현 완료. 명시적 테마 색·인접 높이/서체 반영, 실제 클릭 전파 차단·20초 UI 대기 해제, SPA 문맥의 inline/후속 자막 검증을 수정했다.
- Node 115개·JavaScript 45개/권한·하네스 통과. 브라우저에서 dark/light 전환, 높이 40/40px·48/48px, 마우스/Enter 열기, 무응답 뒤 재클릭 복구 및 기존 DOM 회귀 8개를 확인했다.
- 실제 Chrome/YouTube/Google 전체 통합은 미검증이다. 실제 키를 열람하거나 API를 호출하지 않았다. [트러블슈팅](../troubleshooting/2026-09-06-launcher-theme-size-click.md)에 검증 범위와 근거를 기록했다.
