# 0004 — 확장 설정 UI와 API 직접 호출

> 0.2.0 전환 당시의 구현 기록이다. 모델 직접 입력과 실행별 동의는 [0005](0005-consent-and-model-list.md)의 목록 선택·버전별 최초 동의로 변경했다.

- 상태: 구현·로컬 검증·문서 반영 완료. 실제 Chrome 설치·실제 API 호출은 미검증.
- 사용자 결정: 확장 설정에서 API 키를 입력한다. 로컬 서버를 계획에서 제거하며 기술적으로 꼭 필요한 경우에만 필요성과 근거를 먼저 알린다.
- 범위: Google AI Studio 텍스트 번역의 확장 단독 실행 전환. OpenAI·kie.ai와 이미지·동영상 자막은 후속 범위를 유지한다.

## 변경 계획

1. 설정 UI에 Google API 키·모델 입력, 저장 상태, 키 교체·삭제를 제공한다. 저장 동작은 API를 호출하지 않는다.
2. 키는 `chrome.storage.session`의 `TRUSTED_CONTEXTS`에만 저장한다. 브라우저 종료·확장 재로드 시 다시 입력하며 일반 페이지·content script·로그·응답에는 노출하지 않는다.
3. Google 어댑터와 입력·응답 검증을 확장 내부의 브라우저 호환 모듈로 옮긴다. background가 고정 Google HTTPS 주소를 직접 호출한다.
4. 기존 취소·재시도·응답 검증을 유지한다. 요청 한도와 누적 입력 예산은 확장의 세션 저장소에서 관리하여 worker 재시작·설정 저장으로 초기화되지 않도록 한다.
5. 설정 변경·키 삭제 시 진행 요청을 취소하고 설정 버전이 다른 작업은 거절한다.
6. 로컬 서버 코드, 등록 도구, 서버 예제 설정·환경변수 템플릿과 실행 명령을 제거한다. 사용자 비밀정보 파일이 있더라도 읽거나 삭제하지 않는다. Git 제외 규칙은 과거 비밀정보 파일 보호를 위해 유지한다.
7. 현행 전체 계획·AGENTS·보안 정책·구조·설치 문서를 갱신한다. 과거 구현 기록은 폐기된 설계라는 표시와 새 계획 링크를 남겨 이력을 구분한다.

## 검증

- 가짜 키와 모의 Google 응답으로 직접 호출, 응답 제한, 인증 오류, 재시도, 취소를 검사한다.
- 설정 UI의 저장·교체·삭제, 키가 STATUS와 content 응답에 포함되지 않는지, 외부 송신자·문서 grant 거절을 검사한다.
- 세션 한도와 동시성, 설정 변경 중 요청, worker 재생성 시 예산 유지 검증.
- JS·manifest·하네스·문서 링크 검사와 브라우저 모의 UI 검증.
- 실제 사용자 키는 열람하지 않고 실제 공급자 호출도 하지 않는다.

## 구현 결과

### 반영 사항

- 확장 0.2.0의 API 설정 UI에서 키·모델 입력, 현재 키 유지, 교체·삭제를 제공한다. 저장은 API를 호출하지 않는다.
- `broker.mjs`가 키를 trusted session에 관리하며 `google.mjs`를 통해 Google HTTPS API를 직접 호출한다.
- API 키를 상태 응답과 content script에 전달하지 않는다. 설정 버전·키 변경 취소·동시성·세션 예산 검사를 구현했다.
- Node 전용 Buffer·타이머 의존성을 브라우저 호환 스트림·타이머로 변경했다.
- 서버 실행 코드, ID 등록 도구, 서버 예제 설정, 환경변수 템플릿, npm start/pair 명령을 제거했다. 사용자 비밀정보 파일은 열람·삭제하지 않았다.
- 전체 계획, README, AGENTS, 보안 정책, 저장소·실행 구조, 설치 안내, 트러블슈팅을 갱신했다. 이전 0001·0003은 폐기된 서버 설계를 담은 역사적 기록으로 명시했다.
- 기술적으로 서버가 꼭 필요한 제약이 확인될 경우 근거와 대안을 먼저 알린다는 사용자 지시를 AGENTS와 현행 계획에 반영했다.

모든 테스트는 가짜 키·모의 공급자 응답만 사용했다. Chrome/Google 공식 문서 열람은 기존 허가 범위에서 수행했다.

### 남은 한계

- 실제 Chrome에 설치한 확장과 실제 Google 계정 키의 종단 간 호출은 검증하지 않았다.
- 키는 세션 동안만 보관한다. 브라우저 재시작·확장 재로드 후 다시 입력해야 한다.
- 개발자용 모의 검증 페이지 제공 도구는 제품 의존성이 아니며 API를 중계하지 않는다.
- OpenAI·kie.ai, 이미지 OCR, 영상 자막, 금액 기준 예산은 후속 범위다.
