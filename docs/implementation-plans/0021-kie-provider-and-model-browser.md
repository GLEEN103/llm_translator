# 0021 — kie.ai 공급자·모델 탐색 UI·토큰 축약 (0.13.0)

## 구현 전 계획

- Google 기존 저장 키·동의·통계를 유지하면서 공급자 선택에 kie.ai를 추가한다. 공급자+정확한 모델별 슬롯, 카탈로그의 공급자/키 결합 검증, 활성 공급자에만 요청, 설정 변경 시 취소를 적용한다. 임의 endpoint·타 공급자 키 대체는 금지한다.
- 공식 문서 열람 허가를 받았다. kie.ai는 모델별 chat completions, Claude messages, GPT responses 형식이 다르다. 확인된 경로만 로컬 허용 목록으로 관리하고 공식 `https://docs.kie.ai/llms.txt`를 키 없이 읽어 지원 목록과 교집합을 표시한다. 문서 목록은 계정별 권한/키 유효성 조회가 아니며 UI에 명시한다. 미구현 생성 모델을 번역 모델로 표시하지 않는다.
- 초기 지원: 문서 규격을 확인한 Gemini 계열, GPT 5.2/5.5, Claude Sonnet 4.6/Opus 4.7의 텍스트·YouTube 자막 번역. 모델별 요청/응답 형식을 정규화하고 여러 구간을 하나의 JSON 구조로 요청·ID 검증한다. JSON schema가 문서화된 경로는 schema를 사용하고 나머지는 JSON 지시+엄격한 결과 검증으로 처리한다. 도구/검색/외부 함수 호출은 하지 않는다.
- kie.ai 이미지 예시는 공개 미디어 URL이다. 현행 로컬 픽셀 직접 전송 호환을 확인하지 못했으므로 이미지 번역은 Google에 유지하고 kie.ai 선택 시 API/캡처 전에 명시적으로 안내한다. 파일 업로드·공개 URL 생성·서버를 임의 도입하지 않는다.
- 모델 선택은 계열별 카드, 이름/ID 검색, 계열 필터, 출시일 최근순(공식 날짜 미확인 마지막), 선택 요약과 지원 기능 배지로 바꾼다. 저장 모델도 공급자를 구분하고 새 모델에는 해당 키 직접 입력 원칙을 유지한다.
- kie.ai 응답의 토큰을 기존 스키마로 정규화한다. chat/responses의 completion/output에 reasoning이 포함된 경우 분리하며 추론 상세가 없으면 출력에 포함될 수 있음을 명시한다. Claude는 입력+캐시 생성/읽기와 출력으로 총합을 계산한다. 누락값은 추정 0으로 대체하지 않는다. 통계 필터/모델 묶음도 공급자를 구분한다.
- 화면 토큰은 1,000 단위 K/M/B/T, 소수 첫째 자리 반올림, 불필요한 .0 제거. 저장/합산 원값은 유지하고 정확한 값은 툴팁·접근성 설명에 제공한다. 요청 건수는 일반 숫자 그대로 둔다.
- 동의는 0.13.0 최초 1회 Google 직접 전송 또는 kie.ai를 통한 선택 모델 전달을 안내한다. 새 호스트는 api.kie.ai(키 인증 헤더)와 docs.kie.ai(공개 목록, 키 없음)로 제한한다. 키·원문·헤더 로그 없음, trusted local/session, 실제 유료 호출 없음. 정책 schema13.

## 검증

모의 provider별 요청/출력/usage·오류/취소/재시도·URL/키 경계, Google 기존 슬롯 보존·동일 모델 이름의 공급자 분리·카탈로그 교차 저장 거절·키 삭제/전환, K/M 경계와 정확값 보존, 통계 공급자 필터를 Node로 검증한다. 모의 브라우저에서 공급자 전환/검색/필터/카드 선택/저장/활성화와 토큰 축약을 확인한다. 구문·하네스 이후 기획/구조/보안/사용법/트러블슈팅을 갱신한다.

## 결과

완료. 확장·package 0.13.0, 보안 설정 schema13.

- `kie-models.mjs`에 고정 지원 경로와 공개 목록 교집합, `kie.mjs`에 chat/messages/responses 변환과 토큰 정규화를 구현했다. 기존 Google 저장 슬롯을 보존하고 공급자·모델별 키, 카탈로그, 요청, 본문 캐시, 통계를 분리했다.
- 초기 지원 모델은 Gemini 2.5 Flash/Pro, Gemini 3 Pro/Flash, Gemini 3.1 Pro, Gemini 3.8 Flash, GPT 5.2/5.5, Claude Sonnet 4.6/Opus 4.7의 10개다. 실제 표시는 공식 문서 목록과 교집합을 취한다. 이미지 번역은 Google만 지원한다.
- 설정에 공급자 선택, 계열별 라디오 카드, 이름/ID 검색과 계열 필터, 선택 요약, 기능/출시일 배지를 구현했다. 확인되지 않은 출시일은 추정하지 않는다. 공급자 선택만으로 활성 모델을 변경하지 않는다.
- 팝업·통계는 K/M/B/T/Q로 표시하고 정확한 정수는 title/접근성 설명에 제공한다. 저장·합산 원값과 미확인 표시는 유지한다. 공급자 필터와 공급자+모델별 집계를 추가했다.
- Node 자동 테스트 **157개 통과**, JavaScript **57개** 구문 및 설정·진입점·권한 검사 통과, 하네스 PASS. 모의 응답으로 세 어댑터, 잘못된 출력, SSE 완료 응답, 재시도/취소, 키/카탈로그 경계, 누락 토큰과 축약 경계를 확인했다.
- 모의 브라우저에서 Google 저장 → kie.ai 10개 카드 조회 → GPT 검색·필터·선택·저장 → 기존 Google 재활성화 → 저장 키로 kie.ai 재조회, 빈 검색 결과, 다크 UI를 확인했다. 통계 3.4M/10K와 정확값 툴팁, 팝업 오늘 요약을 확인했고 콘솔 오류는 없었다.
- 화면 검증 중 모델 표가 날짜별 합계를 덮어쓰고 공급자 이름을 잘못 표시하는 구현 오류를 발견했다. `groupUsage`로 공급자+모델 집계를 통일하고 회귀 테스트로 보완했다.
- 실제 키 열람·유료 API 호출·실제 Chrome 확장 통합 검증은 수행하지 않았다. 계정별 모델 권한, 실서비스 응답·지연·번역 품질은 후속 확인 대상이다. 공개 문서 목록 조회는 키 유효성 검사가 아니다. 서버는 추가하지 않았다.
