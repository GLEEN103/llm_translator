# 0017 — 자막 패널 재열기와 닫기 의미 변경 (0.11.1)

## 구현 전 계획

- 기존 재열기는 페이지 버튼 → background 확인/재주입 → OPEN_VIDEO를 다시 거친다. 이미 존재하는 패널의 표시 복원도 worker 응답·문서 재확인 실패에 영향을 받는다. 사용자 환경의 정확한 실패 지점은 아직 확인하지 못했다.
- 같은 영상/연결된 활성 video의 기존 패널은 같은 확장의 isolated world 안에서 즉시 다시 표시한다. launcher의 trusted 클릭에서만 이 경로를 호출한다. 패널이 없거나 영상이 다르면 기존 background 진입을 유지한다. 외부 DOM 이벤트/postMessage 브리지는 추가하지 않는다.
- video-content에 상태를 노출하지 않는 복원 함수만 제공한다. 기존 ON/언어/결과 유지, 패널 hidden·자막 표시 억제 해제와 초점 복원을 수행한다. 새 작업/외부 전송 권한을 부여하지 않는다.
- 자막 패널 헤더의 종료용 닫기를 제거하고 UI 숨기기 이름을 닫기로 변경한다. 닫기는 패널만 숨기며 번역/자막을 유지한다. 번역 중지는 기존 OFF로 수행한다. 영상 이동/탭 종료의 내부 정리 함수는 유지한다.
- 버전, README, 현행 기획/구조/사용법 및 트러블슈팅을 갱신한다. 키/권한/서버/정책 schema는 유지한다.

## 검증

모의 브라우저에서 일반 영상/Shorts의 열기 → ON → 닫기 → 페이지 버튼 재열기를 반복한다. 최초 열기 이후 background 열기 응답을 실패/무응답으로 바꿔도 기존 패널을 즉시 복원하는지, ON/결과가 유지되는지 확인한다. 다른 영상에서는 기존 작업을 복원하지 않고 새 작업 OFF로 시작해야 한다. 기존 Node·구문 검사를 실행한다. 실제 API 키는 사용하지 않는다.

## 결과

- 구현 완료, 0.11.1. 기존 패널 복원은 현재 영상/연결된 host/활성 video 검사 후 로컬로 처리한다. 빈 자막 목록 재시도는 유지한다. 종료용 닫기는 제거하고 패널 숨김 버튼 이름을 닫기로 바꿨다.
- Node 120/120 PASS, JS 48개 구문/JSON/manifest 검사 PASS.
- 모의 브라우저 일반 영상: ON → 닫기 → 열기 응답 오류 → 페이지 버튼으로 즉시 복원, 무응답 상태 반복 복원 PASS. 번역 결과/ON 유지, 번역 1회·취소 0회.
- 모의 브라우저 Shorts: 무응답 상태 닫기/복원, 패널·자막 숨김/복원, 영상 변경 시 기존 패널 정리, 새 작업 OFF PASS. 헤더 종료 버튼 제거 확인.
- 실제 API 호출 0회. 실제 Chrome 설치/YouTube/Google 통합 및 사용자 환경의 정확한 원인은 미검증이다. 기존 재열기 경로의 worker 실패 의존을 제거했다.
- README·기획·사용법·실행/보안 구조·트러블슈팅 갱신 완료. 제품 서버·추가 권한·키 정책 변경 없음.
