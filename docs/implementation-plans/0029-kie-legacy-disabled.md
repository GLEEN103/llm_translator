# 0029 — kie.ai 레거시 비활성화

## 구현 전 계획

- 응답 불안정으로 kie.ai를 선택 불가능하게 한다. 공급자 어댑터·모델·가격·전송 모듈과 단위 테스트는 레거시로 보존한다.
- 설정 공급자 목록에 `kie.ai · 레거시 (사용 중지)`를 비활성 항목으로 표시한다. 기본 편집 대상은 Google이며 기존 Kie 활성 설정이면 사용 중지와 Google 설정 필요를 알린다. 다른 키나 모델로 자동 전환하지 않는다.
- background에서 Kie 목록·가격 조회, 설정 저장·활성화, 번역을 차단한다. 기존 활성 Kie도 configured=false로 반환하여 팝업 실행을 막고 페이지·우클릭·직접 메시지 경로도 차단한다.
- 기존 Kie 키·사용 통계는 삭제하지 않는다. 별도의 레거시 저장 키 영역에서는 키 값 없이 모델 이름과 개별 삭제만 제공한다. 통계 조회와 전체 삭제 기능을 유지한다.
- 변경 대상: broker, options/popup/core 및 동의 문구, 버전 0.15.2, 보안 정책과 관련 테스트·문서. 기존 권한은 레거시 코드와 함께 유지하되 실행 경계에서 외부 요청을 막는다. 새로운 외부 열람/실제 키/유료 호출은 없다.
- 검증: 기존 Kie 활성 프로필에서 상태·번역·재활성화·가격/모델 조회가 차단되고 네트워크·usage가 증가하지 않는지, 보존·개별 삭제와 Google 전환이 가능한지 자동 검사한다. 공급자 비활성 표시도 검사하고 전체 테스트·구문 검사·하네스를 수행한다.

## 구현 결과

- 0.15.2로 반영했다. 공급자 드롭다운의 Kie 항목은 disabled이며 설정 편집은 Google로 시작한다. 기존 Kie 키는 별도 레거시 영역에서 모델명과 삭제 버튼만 표시한다. 일반 모델 선택 목록에는 섞지 않는다.
- broker에서 Kie 가격/목록 조회·저장·활성화를 PROVIDER_DISABLED로 거절한다. 기존 활성 Kie는 configured=false와 사용 중지 안내를 반환하며 전송 동의/실행 검사에서 원문 수집·번역 경로를 막는다. YouTube 인라인 버튼은 설정 페이지로 안내한다. API 어댑터와 단위 테스트는 보존했다.
- 키·통계·활성 슬롯을 자동 삭제/변경하지 않는다. 다른 Google 키로 자동 전송하지 않으며 명시적 Google 저장·활성화 후에만 사용할 수 있다. 레거시 키 삭제 후에도 통계와 Google 키는 유지한다.
- 전체 자동 테스트 **220개 PASS**, JavaScript **65개** 구문·설정 검사 PASS, 보안 하네스 PASS. 신규 검증은 기존 Kie 활성 상태·모델/가격/번역 차단·네트워크와 예산 미증가·키 삭제·Google 전환·인라인 설정 안내·자막 자동 반복 중단을 포함한다. options HTML의 비활성 옵션과 별도 삭제 영역도 직접 확인했다.
- 최초 전체 검증에서 새 사용 중지 안내에도 기존 진단 코드 괄호 형식을 요구한 테스트가 실패했다. 해당 안내의 Google 전환 문구를 확인하도록 테스트 기대를 분리한 후 전체 220개가 통과했다.
- 실제 키/외부 호출 및 이번 변경의 실제 Chrome UI 조작은 수행하지 않았다. 기존 Chrome 전송 smoke는 현재 비활성화된 레거시 모듈 검증용으로 남긴다.
- README·제품 범위·실행 구조·보안 정책·개발 안내·AGENTS에 현재 사용 중지 상태와 과거 Kie 기록의 구분을 반영했다. 서버/신규 권한은 추가하지 않았다.
