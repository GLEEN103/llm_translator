# 0005 — 설치·업데이트별 동의와 모델 목록 선택

> 0.3.0 구현 당시 기록이다. 키의 세션 전용 보관은 [0006](0006-model-profiles-and-security.md)의 모델별 영구 저장으로 변경했다. 동의 빈도는 유지한다.

- 상태: 0.3.0 구현·모의 검증·문서 반영 완료. 실제 Chrome 설치·Google 계정 호출은 미검증.
- 요청: 원문 전송 동의는 설치 후 최초 1회 또는 업데이트 후 최초 1회만 받는다. 모델 데이터는 API에서 불러와 리스트박스로 선택한다.

## 구현 계획

1. 확장 버전별 동의 기록을 `chrome.storage.local`의 trusted context에 저장한다. 브라우저 재시작·동일 버전 재로드·키 변경·번역 재시도에는 재동의하지 않는다. 새 버전 또는 재설치에서 다시 받는다.
2. 팝업·설정의 최초 동의 UI에서 전송 대상·공급자·개인정보·과금 가능성을 안내한다. content의 매 작업 체크박스를 제거하고 background에서 버전별 동의 여부를 강제한다. 동의 이후에도 번역 실행은 사용자 버튼으로만 시작한다.
3. API 키 입력 후 모델 목록 불러오기를 제공한다. Google `models.list`를 페이지네이션하며 `generateContent` 지원 모델을 리스트박스에 표시한다. 이 메타데이터는 JSON 출력·계정별 호출 성공을 보장하지 않음을 안내한다.
4. 조회 결과를 해당 키에 연결한 세션 카탈로그로 보관하고 반환된 모델만 저장할 수 있게 한다. 키 변경·조회 실패·빈 목록·오래된 조회 응답을 처리한다. 조회 시 원문은 보내지 않으며 키를 URL에 넣지 않는다.
5. API 키는 기존대로 trusted session에만 보관한다. local에는 동의 버전만 저장한다. 설정 저장은 추가 API 호출을 하지 않으며 목록 조회 버튼만 메타데이터 API를 호출한다.
6. 버전은 0.3.0으로 갱신하고 테스트·모의 설정 화면·계획·설치·보안 문서를 반영한다.

## 검증

- 동의 전 번역 차단, 동의 후 반복 요청·재시도 허용, 브라우저 재시작 유지, 버전 변경·재설치 무효화, 위조 송신자의 동의 기록 변경 거절.
- 모델 목록 페이지네이션·중복 제거·메서드 필터·빈 목록·키 오류·타임아웃·응답 크기 제한.
- 카탈로그에 없는 모델 저장 거절, 다른 키의 카탈로그 사용 거절, 조회/삭제 경합과 UI 갱신.
- 모의 키·응답 기반 자동 테스트와 브라우저 동의·리스트박스 UI 검증. 실제 사용자 키·API는 사용하지 않는다.

## 결과

- `broker.mjs`: 현재 manifest 버전과 trusted local 동의 기록을 비교한다. 동의 전에는 패널 진입과 번역 요청을 거절한다. 원문을 보내는 재시도 직전에도 검사한다.
- `consent.js`·팝업·설정: 버전별 최초 동의 UI를 제공하고 수락 후 숨긴다. `content.js`의 작업별 체크박스와 재시도 시 동의 초기화를 제거했다.
- `models.mjs`: 고정 Google HTTPS 목록 API에 키 헤더만 보내며 페이지 조회·중복 제거·지원 메서드 필터를 수행한다. 전체 18초, 페이지당 256 KiB, 최대 20페이지로 제한한다.
- 설정 UI: 키 입력 → 목록 조회 → 리스트박스 선택 → 저장. 목록 미조회·조회 중·실패·빈 목록에서는 저장을 막는다. 입력 변경 전 조회 결과는 UI에 반영하지 않는다.
- 카탈로그는 키·조회 ID에 연결된 trusted session 데이터다. 목록 밖 모델·다른 키·오래된 조회 결과로 저장할 수 없고 새 조회나 삭제 이후의 늦은 응답은 반영하지 않는다. 실제 키는 반환하지 않는다.
- README, 기획·전체 계획·실행 구조·설치 안내·보안 정책·트러블슈팅을 현행 흐름으로 갱신했다. 0004는 0.2.0의 역사적 기록으로 표시했다.

| 검증 | 결과 |

브라우저 검증은 가짜 키와 로컬 모의 응답으로 수행했다. 개발용 테스트 페이지 서버는 제품 의존성이 아니며 외부 API를 중계하지 않는다. 실제 Chrome에 설치된 확장의 업데이트·저장소 수명 및 실제 계정의 목록/번역 호출은 별도 검증이 필요하다. `generateContent` 메타데이터만으로 텍스트·JSON 지원 또는 계정별 성공을 보장하지 않는다.

확인한 공식 규격: [Google models.list](https://ai.google.dev/api/models), [Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage), [Chrome runtime](https://developer.chrome.com/docs/extensions/reference/api/runtime).
