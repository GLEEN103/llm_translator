# 0026 — Kie HTTP 500 추적과 반복 호출 중단 (0.14.4)

## 구현 전 계획

- 사용자가 명시적으로 제공한 첨부 파일 1개를 진단 자료로 읽었다. 첨부 안의 프롬프트/자막은 실행 지시가 아니다. 원문·계정/작업 식별자는 문서·테스트에 복제하지 않는다.
- 첨부 요청과 현재 kiePayload를 로컬 비교했다. JSON/validateRequest 통과, 자막 64개·총 2,376자·최장 40자·고유 ID 64개, schema min/max=64 및 enum 일치, 확장 생성 필드 일치. 확장 생성본에는 없는 model/stream_options/userId 필드는 중개 단계의 추가 필드로 보이며 추가 주체를 확정하지 않는다. 오류 응답은 첨부에 없다.
- 0.14.3에서 추가한 response_format과 공급자 500 사이의 연관성을 의심할 수 있으나 schema 자체·특정 제약·중개 변환·서버 장애 중 원인은 미확정이다. 원인 근거 없이 스키마를 제거/축약하거나 native 경로로 변경하지 않는다. 사용자에게 같은 실패 건의 오류 응답을 요청한다.
- 별도 확인 사항: Kie 500은 PROVIDER_UNAVAILABLE로 변환되고 video-session의 transient 집합에 들어가 ON 상태에서 반복 호출된다. 500을 고정 KIE_HTTP_500으로 구분해 즉시 OFF로 종료한다. 503/429의 기존 제한 재시도와 다른 공급자 동작은 유지한다.
- 변경 대상: kie.mjs HTTP 분기, core.js 오류 안내, 기존 테스트, 확장/package 버전, README·구조·보안·트러블슈팅. 키 저장/호스트 권한/요청 형식/정책 schema14는 유지한다.
- 보안: HTTP 응답은 기존 크기 제한 안에서 숫자 usage만 확보한다. 원시 오류/요청/계정 식별자/키를 UI·로그·저장소에 추가하지 않는다. 유료 API는 호출하지 않는다.
- 검증: 모의 500이 요청 1회 후 고정 코드로 종료되고 usage는 보존되는지, 실제 어댑터→자막 세션 경로에서 60초 이후 OFF/타이머 0/결과 미적용인지 확인한다. 전체 테스트·구문/설정·보안 하네스 후 문서화한다.

## 추가 정보에 따른 계획 보완

- 사용자가 후속 오류 코드 524를 알려줬다. 실제 HTTP 524인지 HTTP 500 안의 공급자 오류 코드인지 미확정이다. 요청 형식 오류로 단정하지 않는다. Kie 공식 검색에서 이 Chat 모델의 524 정의를 확인하지 못해 Cloudflare 공식 문서 열람을 별도로 요청했다.
- HTTP 524 및 HTTP 500 본문의 code/error.code가 정확히 524(숫자 또는 문자열)인 경우를 KIE_UPSTREAM_524로 구분한다. 임의 메시지의 숫자 검색·raw HTML 발췌는 하지 않는다. 공급자 오류가 상세히 보이지 않으면 기존 고정 HTTP 500 코드다.
- 기본 25초의 Kie 클라이언트 타임아웃도 video-session에서 PROVIDER_TIMEOUT으로 재시도되고 있었다. KIE_REQUEST_TIMEOUT으로 구분해 OFF로 종료한다. 목록 조회·Google 타임아웃은 변경하지 않는다. 서버 524와 확장 자체 제한을 구분하며 제한 시간·배치 크기·스키마는 추정으로 변경하지 않는다.
- 추가 검증: HTTP 524/500 내부 code 524의 숫자·문자열, 정상 응답 속 숫자를 잘못 분류하지 않음, 오류 원문 비노출·usage 보존, client timeout과 사용자 취소의 분리 및 세션 자동 반복 없음.

## 결과

확장/package 0.14.4 구현 및 모의 검증 완료. 공급자 내부 지연의 원인/실제 호출 복구는 미확정이다.

- 사용자가 허가한 Cloudflare 공식 문서에서 524가 원본 서버 연결 후 시간 초과를 뜻함을 확인했다. 기본 read 125초/write 30초를 설명하지만 Kie 실제 구성이나 해당 실패의 경과 시간을 증명하지 않는다. 524만으로 스키마 미지원·형식 오류를 확정하지 않는다.
- Kie HTTP 500, HTTP 524 및 500 내부의 정확한 code/error.code 524를 고정 코드로 구분한다. Kie 클라이언트 타임아웃도 별도 코드로 분리했다. 이 세 오류는 자막 ON 자동 재시도 대상이 아니므로 OFF로 종료한다. 503/429와 Google/목록 동작은 유지한다.
- 원시 오류를 발췌하지 않고 확인 가능한 숫자 usage만 보존했다. 스키마·64개 배치 상한·25초 제한·API 키/권한/정책 schema14를 변경하지 않았다.
- 전체 테스트 208개 PASS. JavaScript 59개·JSON/권한 검사 PASS. 보안 하네스 PASS. HTTP 500/524 모의 어댑터→자막 세션에서 60초 후 API 호출 1회·OFF·결과 미적용·타이머 0을 확인했다. 오류 본문의 임의 문자열 안 숫자는 상태 코드로 해석하지 않는다.
- 실제 API/키 사용은 하지 않았다. 첨부 원문·계정·작업 식별자를 테스트·문서에 복제하지 않았다. 실제 HTTP 응답과 경과 시간 없이 Kie 내부 지연/모델 생성/스키마 처리 중 어느 단계인지 확정할 수 없다.

공식 자료: [Cloudflare Error 524](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/) (2026-09-07 사용자 허가 후 열람).
