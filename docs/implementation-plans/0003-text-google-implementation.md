# 0003 — 텍스트와 Google AI Studio 최초 구현

> 0.1 버전의 역사적 기록이다. 아래 로컬 서버·연결 토큰·서버 전용 키 설계와 해당 실행 코드는 사용자 지시에 따라 제거했다. 현행 확장 단독 구조·검증은 [0004](0004-extension-direct-api.md)를 따른다. 아래 테스트 수치는 당시 결과다.

- 상태: 코드·로컬 검증·문서 반영 완료. 실제 Chrome 설치·Google API 연동 검증 미실시.
- 근거: 0002 전체 계획의 1~4단계. 추가 공급자·이미지·영상은 후속 범위로 유지한다.
- 사용자 요청: 전체 계획을 기준으로 실제 구현 진행.

## 구현 결정

- 외부 패키지 없는 JavaScript와 Node.js 내장 기능으로 로컬 서비스를 구현한다. 확장은 빌드 없이 로드하는 Manifest V3 구조로 구성한다.
- 기본 로컬 주소는 `http://127.0.0.1:43187`이다. 공급자 통신은 고정 HTTPS 호스트만 사용한다.
- 로컬 서비스는 등록된 확장 ID, Host 검사, 실행 시 생성하는 별도 연결 토큰으로 인증한다. 공급자 키는 루트 `.env.local`에서만 로딩하며 확장에 전달하지 않는다.
- 연결 토큰은 `.secrets/connection-token.txt`에 생성한다. 사용자가 확장 설정에 입력하며 확장은 브라우저 세션 동안 trusted context 저장소에만 보관한다.
- 선택 텍스트·본문 수집과 진행 UI는 content script가 담당한다. 확장 background는 인증된 로컬 요청만 중계한다.
- 사용자 실행 후 전송 범위·문자 수를 보여주고 매 작업 명시적 동의를 받는다. 본문은 원문을 유지하고 번역문을 추가한다.
- 분할, 요청 큐, 작업별 중복 캐시, 부분 실패·재시도·취소, 원문 변경·노드 제거·탭 이동에 대한 응답 적용 검사를 구현한다.
- 모델은 서버 설정으로 지정한다. 임의 API URL은 허용하지 않는다. 공급자별 변환 경계는 별도 모듈로 둔다.

## 변경 대상

- `src/extension/`: manifest, background, popup, options, content script 및 UI.
- `src/server/`: 설정·인증·HTTP 서비스, Google 어댑터, 요청·응답 검증.
- `tools/`: 설정 보조 도구, 자동 테스트와 로컬 검증용 페이지.
- 루트 `package.json`, `.env.example`, 공개 서버 설정 및 기존 하네스 검증 도구.
- `docs/architecture/`, `docs/troubleshooting/`, `docs/planning/`, `README.md`: 실제 동작·설치·한계 반영.

## 검증

- Node 내장 테스트로 인증·Origin·Host·요청 크기·형식·호출 제한, 공급자 HTTP 실패·응답 검증·타임아웃을 검사한다. 실제 키를 로딩하지 않는다.
- 추출·분할·응답 적용·취소 등 확장 로직은 가능한 로컬 테스트로 검증한다. 실제 Chrome UI 확인 여부는 별도 기록한다.
- JSON 파싱, JS 문법, 하네스 검사와 문서 링크 검사를 수행한다.
- 실제 공급자 호출은 키 제공·호출 허가가 있는 경우에만 수행한다. 없으면 가짜 응답 기반 검증과 실제 연동 미검증을 구분한다.

## 외부 규격 확인

사용자가 Google AI와 Chrome 개발자 공식 문서 열람을 허가했다. 허가 후 REST generateContent, API 키 인증, 확장 권한·저장소·메시지 송신자 규격을 확인했다. 출처는 [실행 구조](../architecture/runtime.md)에 기록했다.

## 구현 결과

### 구현 사항

- Manifest V3 확장: 선택/본문 번역 진입, 원문 미리보기와 실행별 동의, 언어 선택, 원문 아래 번역 표시, 취소·부분 실패 재시도·원문 복원.
- 추출: 폼·편집·숨김·미디어·프레임 제외, 인라인 공백 보존, 큰 본문 제한·분할, 원문 변경과 제거 검사.
- 작업 조정: 순차 배치, 작업 내 중복 원문 재사용, 작업 ID·문서 ID·grant, 세션 저장소를 통한 worker 재시작 대응, 모델 변경 검증.
- 로컬 서비스: 등록된 확장·Bearer 인증, Host·Origin 검사, 루프백 수신, 크기·동시성·빈도·누적 입력 한도, 연결 종료 시 공급자 요청 취소.
- Google 어댑터: 고정 HTTPS 호스트, 서버 키 헤더, JSON 응답 검사, 오류 비식별화, 제한적 429·503 재시도와 시간 제한.
- 설치 보조 도구, 가짜 응답 자동 테스트, 실제 DOM을 사용하는 로컬 브라우저 검증 페이지, 설치·구조·보안·문제 해결 문서.

- 제품 범위, 저장소·실행 구조, 보안 문서와 AGENTS의 현재 구현 상태를 갱신했다.

### 미실시 검증과 후속 범위

- 실제 Chrome 개발자 모드 설치와 실제 Google API 키를 사용하는 종단 간 번역은 수행하지 않았다. 사용자의 확장 설치·키/모델 설정 후 짧은 비민감 문장으로 확인해야 한다.
- 모델별 품질·지연·쿼터, 다양한 사이트 레이아웃, Chrome 버전별 설치·로컬 연결 동작은 추가 검증이 필요하다.
- 금액 기준 예산, 자동 설치·배포·CI, Windows ACL 자동 설정은 구현하지 않았다.
- OpenAI·kie.ai, 이미지 OCR, 동영상 자막은 계획대로 후속 구현사항이다.
- 프로젝트 밖 로컬 파일·메모리·전역 스킬·실제 비밀정보는 읽지 않았다. 외부 규격 확인은 사용자가 허가한 공식 문서를 근거로 했다.
