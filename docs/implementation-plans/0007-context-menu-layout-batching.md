# 0007 — 우클릭 선택 번역·레이아웃 보존·구조화 묶음 요청

- 상태: 0.5.0 구현·모의 검증·문서 반영 완료. 실제 Chrome 메뉴·Google 계정·사용자 문제 사이트는 미검증.
- 요청: 선택 번역은 우클릭 메뉴, 본문 양식 붕괴 수정, 여러 요소를 하나의 구조화 요청·응답으로 처리.

## 확인한 원인

- 본문 표시는 각 조상 요소에 display:block, padding, margin이 강제된 번역 span을 추가한다. flex/grid 항목 증가, 표/제목 크기 증가, 인라인 조상에 블록 삽입을 유발할 수 있다.
- 기존에도 JSON 배열 요청이지만 최대 8구간·6,000자 제한이다. 작은 텍스트가 많은 페이지에서 호출 수가 늘어난다. 응답 스키마는 프롬프트에만 적혀 있다.

## 구현

1. Chrome contextMenus의 selection 메뉴를 등록한다. 팝업의 선택 번역 버튼은 제거한다. 메뉴 클릭의 selectionText를 작업 메모리로 전달해 포커스 변경으로 선택이 풀려도 동일 원문을 사용한다. HTTP(S) 메인 프레임만 지원하고 editable/자식 프레임은 거절한다. 동의/설정 미완료·실행 오류는 설정 화면에서 안내한다. 키·원문을 로그/영구 저장하지 않는다.
2. 본문은 원래 Text 노드의 값만 번역으로 교체한다. 태그·속성·스타일·링크·이벤트·flex/grid 자식 수를 유지한다. 각 노드를 독립 ID로 연결하고 원문/적용 문자열·부모 참조를 메모리에 보관한다. 복원은 아직 확장이 적용한 값과 같은 노드만 되돌려 페이지의 후속 변경을 덮어쓰지 않는다. 번역 길이에 따른 자연스러운 줄바꿈 변화는 가능하다.
3. 노드/긴 텍스트 분할 구간을 최대 64개·12,000 UTF-16 코드 단위까지 하나의 segments 배열로 묶는다. 요청 횟수는 요소 수가 아닌 묶음 수다. Google 응답 스키마를 명시하고 translations 배열을 ID로 파싱한다. 누락/중복/미지 ID/비정상 응답은 묶음 단위로 거절하며 응답 순서는 무관하다.
4. 응답 텍스트 한도 48,000, 출력 토큰 16,384, 번역 타임아웃 25초로 조정한다. 응답 바이트 제한은 기존 256 KiB를 유지한다. 모델 목록 조회는 18초 유지. 자동 재시도·취소·사용량 차감은 묶음 요청 단위로 유지한다.
5. 버전 0.5.0과 contextMenus 권한을 반영하고 원문 복원·레이아웃·구조화 요청 수·응답 연결·선택 메뉴·오류·취소를 모의 검증한다. 보안 및 설치/구조/문제 해결 문서를 갱신한다.

## 검증

- 공식 contextMenus 등록/클릭 API와 activeTab 권한 흐름 확인. callback 등록으로 최소 Chrome 112 호환 유지.
- 40개 짧은 요소가 한 요청인지, 64개/12,000자 경계와 긴 구간 무손실 재결합, 스키마·응답 순서·잘못된 ID 검증.
- 브라우저 실제 DOM의 flex/grid/table/inline 태그·자식 수·링크 이벤트 보존, HTML 비실행, 복원·페이지 변경 보호.
- 가짜 키·모의 응답만 사용. 실제 Chrome 설치 메뉴 및 실제 API·사용자 문제 사이트 검증은 구분해서 기록.

## 결과

- 팝업에서 선택 진입을 제거하고 selection 전용 우클릭 메뉴를 설치/브라우저 시작 때 등록한다. 클릭 탭·선택 문자열을 사용하고 URL 검사 및 documentId 고정으로 주입한다. 오류는 안전한 코드로 설정에 안내한다.
- 본문은 노드별 ID와 원문·부모·적용 문자열을 기억해 값만 변경한다. 번역 span·강제 블록/여백을 제거했고 조건부 복원으로 페이지 후속 변경을 보존한다.
- 요청은 64구간/12,000자 상한으로 묶고 Google responseJsonSchema를 지정한다. 응답 순서를 뒤집어도 ID로 정확히 연결하며 한도·취소·실패·재시도를 유지한다.
- 버전/권한, README·기획·전체 계획·구조·설치·보안·문제 해결 문서를 갱신했다.

모든 실행 검증은 가짜 키·모의 API를 사용했다. 실제 Chrome 메뉴 통합과 Google 응답 시간/스키마 호환, 사용자 문제 사이트는 별도로 검증해야 한다. 번역문 길이에 따른 자연스러운 줄바꿈을 고정하는 기능은 추가하지 않았다. 로컬 서버는 제품에 도입하지 않았다.
