# 0010 — YouTube 자막 번역 (v0.8.0)

## 목적과 범위

- 데스크톱 YouTube 일반 시청 페이지에서 제공되는 수동 자막 또는 자동 생성 자막을 목록으로 불러온다. 사용자가 자막과 목표 언어를 선택하고 번역을 시작한다.
- 영상·음성 인식/다운로드/전송은 하지 않는다. 자막 텍스트만 기존 Google 구조화 번역 API에 보내고 타임코드는 기기에 남긴다. 서버를 추가하지 않는다.
- 반투명 자막을 영상 위에 표시한다. 재생 시간(`video.currentTime`)을 기준으로 일시정지·탐색·배속·전체화면을 처리하고, 표시 ON/OFF 및 종료를 제공한다.
- 최초 범위는 `https://www.youtube.com/watch?v=...`의 녹화 영상이다. Shorts·임베드·라이브·자막이 없는 영상·접근 제한 우회는 제외한다.

## 구현 순서와 변경 대상

1. `youtube-captions.mjs`: 문서에 고정한 MAIN world 실행으로 플레이어의 현재 영상/자막 메타데이터를 읽고, 해당 페이지와 동일 출처의 `/api/timedtext`만 요청한다. API 키·확장 grant는 MAIN world로 전달하지 않는다. 응답은 신뢰하지 않고 크기·영상 ID·타임코드·텍스트를 다시 검증한다. 자막 URL은 사용자/LLM 응답에 포함하지 않는다.
2. `video-core.js`: JSON3 자막을 시간 구간으로 정규화하고 자동자막 append를 합친다. 현재 시점 이후 구간을 우선하여 여러 자막을 한 구조화 요청에 묶는다. 반복 문장은 작업 내에서 재사용한다. 번역이 아직 준비되지 않은 구간에서는 과거 번역을 표시하지 않는다.
3. `video-content.js`: 독립된 closed shadow UI, 자막/언어 목록, 시작/중지·재시도·ON/OFF·닫기. 타이밍은 원문 구간으로만 결정한다. 광고·영상 변경·페이지 이동·플레이어 제거 시 이전 번역을 숨기고 취소한다. 결과는 오버레이 작업 메모리에만 보관한다.
4. `broker.mjs`/팝업: YouTube 자막 번역 진입점, 기존 문서 grant/동의/모델별 키/요청 제한을 재사용한다. 자막을 읽는 메시지에도 현재 YouTube URL·문서·영상 ID를 검증한다.
5. 버전·동의 문구·보안 정책·기획/구조/사용법/트러블슈팅 문서를 반영한다.

## 제한과 실패 처리

- 자막 공급 경로는 YouTube 플레이어 구현에 의존한다. 권한·서명·플레이어 변경으로 읽을 수 없으면 구체적인 오류를 표시하고 사용자에게 자막 활성화/페이지 새로고침을 안내한다. 외부 다운로드 서비스·토큰 우회·비공개 클라이언트 위장은 사용하지 않는다.
- 최대 5,000개 원시 자막 이벤트, 100,000자, 2 MiB 응답. 한 번역 요청 최대 64개/12,000자, 항목당 2,400자. 기존 세션 문자 예산·분당 호출 제한을 유지한다. 순차 요청으로 현재 시점 주변부터 미리 번역한다.
- 설치/업데이트 버전당 최초 1회 동의에 자막 텍스트 전송을 추가한다. 영상 URL·제목·쿠키·서명·음성·영상 프레임은 Google로 전송하지 않는다.
- 번역 UI 종료/페이지 이동 시 자막·결과 메모리를 폐기한다. 네트워크에 이미 전송한 번역 요청은 취소해도 과금될 수 있다.

## 검증 계획

- Node 테스트: 자막 파싱, append·동시/빈 구간·잘못된 타임코드·한도, seek/배속과 시간 검색, 구조화 배치/반복 문장, 출처/영상/문서 경계, 공급자 전송에 타임코드/URL 미포함, 실패와 취소.
- 로컬 공개 더미 영상/자막과 모의 공급자로 브라우저 UI·재생/일시정지/탐색/ON-OFF·지연 응답/닫기·오류를 확인한다. 실제 API 키를 사용하지 않는다.
- 기존 자동 테스트, 구문 검사 및 하네스 검사. 실제 Chrome 확장/YouTube/Google API 통합 테스트의 수행 여부를 구분해 기록한다.

## 자료

- [Chrome scripting: documentIds, MAIN world, Promise 반환](https://developer.chrome.com/docs/extensions/reference/api/scripting)
- [Gemini 구조화 응답](https://ai.google.dev/gemini-api/docs/structured-output)
- 사용자에게 YouTube 공식 문서와 공개 테스트 영상 열람 허가를 받았다.
- [YouTube captions.download](https://developers.google.com/youtube/v3/docs/captions/download): 영상 편집 권한 및 OAuth가 필요하므로 일반 시청자의 자막 수집 경로로 사용하지 않는다.
- [YouTube 자동 자막](https://support.google.com/youtube/answer/6373554?hl=ko): 자동 생성 자막은 영상에 따라 제공되지 않거나 오류가 있을 수 있다.
- [YouTube 스크립트 보기](https://support.google.com/youtube/answer/15930243?hl=en): 사용자가 자막 제공 여부를 확인하는 경로. 플레이어 내부 JSON3 수집 API를 보장하는 문서는 아니다.

## 구현 결과

v0.8.0 구현 완료. YouTube 전용 팝업 진입점, 제작자/자동 생성 트랙 목록, 목표 언어 선택, JSON3/append 파싱, 현재 시점 우선 구조화 순차 번역, 반투명 오버레이 및 ON/OFF·중지/재시도·접기/닫기를 추가했다. 영상 탐색/일시정지/배속/전체화면을 영상 시계로 처리하고 광고·빈 구간·지연 응답·SPA 이동을 처리한다.

API 키의 기존 모델별 trusted local 정책을 유지했다. 자막은 작업 메모리에만 보관하고 Google에 타임코드/영상 정보 없이 텍스트만 보낸다. 버전별 최초 동의 문구와 schema v7 정책을 반영했다. 로컬 서버·상시 YouTube 호스트 권한·추가 외부 패키지는 필요하지 않다.

검증: `npm test` 84개 통과, `npm run check` JavaScript 37개/JSON/권한 검사 통과, `tools/verify-harness.ps1` 통과. 기존 브라우저 텍스트 40개·이미지 10개 검사가 통과했다. 신규 로컬 UI에서 자막 선택/목표 언어, 실제 미디어 시계/탐색/2배속/일시정지, 전체화면, ON/OFF·접기·닫기, 광고·영상 이동, 오류/재시도, 취소 뒤 늦은 응답 무시를 확인했다.

공개 YouTube 테스트 페이지는 열었으나 테스트 브라우저에서 자막 사용 불가로 표시되어 실제 자막 수집 성공을 검증하지 못했다. 실제 Chrome 확장 및 Google 실제 API를 합친 통합 검증은 미실시다. 키를 열람/사용하지 않았으며 API 과금 호출도 하지 않았다. 수집 구현은 플레이어 내부 트랙/timedtext 변경에 영향을 받을 수 있다. 자세한 증거·제약은 [트러블슈팅](../troubleshooting/2026-09-06-youtube-captions.md)을 따른다.
