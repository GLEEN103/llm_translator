# 0032 응답 형식 재시도·구간 오류 격리·최근 영상 번역 저장

## 목적과 범위

- JSON/스키마/구간 ID 등 응답 형식 오류는 최초 요청 후 최대 3회 재시도한다(최대 4번의 형식 검증 시도). 본문·부분·이미지·자막에 적용한다.
- 재시도 간 5초 대기하며 동시 5개·최근 60초 60회·사용량/문자 예산을 모두 유지한다. 로컬 동시/분당 한도 대기는 형식 재시도 횟수를 소비하지 않는다.
- 최종 형식 실패는 해당 묶음만 오류 처리한다. 자막 ON을 유지하고 나머지 구간 및 새로 수집된 자막은 계속 번역한다. 실패 원문은 자동 큐에서 제외해 무한 반복을 막고 사용자가 실패 구간을 다시 시도할 수 있게 한다.
- 현재 문서 UI에 시각·오류 코드·묶음 구간 수·재시도/최종 실패를 표시하는 최대 100행 오류 로그를 제공한다. 키·원문·모델 원시 응답·스택은 로그에 넣지 않는다.

## 최근 영상 저장 설계

- background가 검증한 성공 번역을 묶음 완료마다 trusted `chrome.storage.local`에 저장한다. 오류·페이지 이동·브라우저 재시작 뒤에도 재사용한다.
- 최근 사용한 YouTube 영상 ID 최대 30건을 LRU로 유지한다. watch/Shorts는 같은 영상 ID를 공유한다. 공급자·정확한 모델 ID·원문/목표 언어와 원문 SHA-256이 일치하는 구간만 재사용하고, 키 교체/설정 revision 변경만으로 성공 번역을 무효화하지 않는다.
- 타임코드는 현재 자막에서 다시 읽어 오버레이에 사용한다. 저장 데이터는 영상 ID·모델/언어 구분·원문 해시·번역문이며 영상 제목/URL·음성·영상·키·원시 공급자 응답은 저장하지 않는다.
- 캐시는 확장 local 저장소의 다른 데이터 공간을 고려해 총 4 MiB로 제한한다. 30건 또는 용량 초과 시 오래 사용하지 않은 영상부터 제거한다. 매우 큰 단일 영상도 상한 내 최근 구간만 보존하며 저장 축소/실패는 UI에 안내한다.
- options에서 캐시 건수/용량 확인과 전체 삭제를 제공한다. 콘텐츠에는 현재 영상·현재 동의·문서 grant·현재 설정으로 요청한 구간의 번역만 반환한다. 임의 캐시 쓰기 API는 제공하지 않는다.

## 변경 대상

- core의 재시도/오류 로그 UI 공통 기능, content/image-content/video-session/video-content의 구간 처리.
- 새 `video-cache.mjs`와 broker의 검증·캐시 조회/병합/관리 경로.
- options·동의 안내·보안 정책·manifest 0.18.0·하네스·회귀/브라우저 검증 도구.

## 보안 영향과 예외

- 사용자 요청에 따라 영상 번역문을 평문 local 저장한다. 해시는 암호화 금고가 아니며 프로필 접근자로부터 번역문을 숨기지 않는다. 동기화/원격 저장/새 서버는 추가하지 않는다.
- `INVALID_PROVIDER_RESPONSE`, `OPENAI_RESPONSE_JSON`, `OPENAI_RESPONSE_FORMAT`만 형식 재시도 대상으로 삼는다. 명시적 거절·불완전 생성·네트워크/시간 초과·인증·예산·설정/영상 변경은 기존의 분리된 처리를 유지한다. Kie는 계속 비활성이다.
- 저장 실패 때문에 완료된 번역을 재요청하지 않는다. 캐시 삭제 중 진행된 요청이 옛 데이터를 되살리지 않도록 저장 세대를 검사한다.

## 검증

- 3회 이내 복구/4번째 형식 실패, 한도 대기 제외, 취소/설정 변경, 동시 일부 실패 격리와 자동 큐 제외/수동 재시도, 안전한 로그를 검증한다.
- 캐시의 30개 영상 LRU·용량·정확한 범위 분리·원문 변경·동시 병합·재시작/탭 종료 재사용·권한 차단·저장 실패·삭제 경합을 테스트한다.
- 허가된 격리 Chrome에서 가짜 응답으로 실제 UI·재시도·로그와 자막 ON 유지/캐시 재사용을 확인한다. 실제 키/유료 API 호출은 하지 않는다.
- 전체 자동 테스트, 구문 검사, 보안 하네스와 관련 문서 갱신을 완료한다.

- **0.18.0 / 보안 정책 schema18**로 구현했다. 형식 오류 최대 3회 추가 재시도, 자막 ON 유지/실패 묶음 제외, 100행 오류 로그와 실패 구간 수동 재시도, 최근 영상 캐시와 options 관리 화면을 제공한다.
- **자동 테스트 270개 통과**: 최대 횟수/마지막 재시도 복구, 로컬 한도 대기 제외, 모든 실제 시도의 예산·토큰 집계, 취소, 실패 구간 자동 큐 제외와 나머지 처리, 원문 ID 변경, 30개 LRU, 용량, 해시/모델/언어 범위, 동시 병합, 탭 종료/재시작, 권한/동의, 저장 실패와 삭제 경합을 확인했다.
- `node tools/check.mjs`: **JavaScript 78개**와 JSON·권한 검사 통과. `tools/verify-harness.ps1`도 통과했다. 마지막 브라우저 스크립트의 대기 보완 뒤 해당 파일의 구문 검사를 추가 통과했다.
- 실제 격리 **Chrome 152.0.7977.77**에서 가짜 자막 128개를 두 묶음으로 전송했다. 한 묶음의 형식 오류는 최초+3회로 종료되고 다른 64구간은 성공했다. 자막 ON, `[번역 오류]`, 로그 4행(재시도 3행+최종 실패)이 확인됐다. 수동 재시도로 복구 후 페이지 재진입에서는 전체 128구간을 캐시에서 복원해 누적 모의 API 요청 **6회 → 6회**로 유지됐다.

- 최종 결과: `tools/.tmp/openai-smoke-1788717498220/result.json` (`ok: true`). 화면: 같은 폴더의 `video-retry.png`, `video-retry-360.png`. 앞선 브라우저 fixture의 짧은 가짜 키/모델 목록 형식과 프레임 반영 전 확인 경합을 수정한 뒤 최종 재검증했다. 실행한 전용 Chrome은 종료했다.
