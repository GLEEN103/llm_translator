# 0023 — 모델명 옆 가격과 좁은 화면 가독성 (0.14.1)

## 구현 전 계획

- kie.ai 카드의 모델명과 가격을 같은 상단 행의 좌우 열에 배치한다. 입력/출력 가격은 오른쪽에서 두 줄로 구분하고 USD/100만 토큰 단위를 표시한다. 기존 하단 가격 영역과 구분선을 없애 카드 높이를 줄인다.
- 입력은 파란색, 출력은 보라색의 글자·배경으로 구분하며 입력/출력 문구도 유지한다. 라이트/다크 모두 읽히는 대비를 적용하고 이전값은 흐리게 만드는 대신 명시적인 재확인 문구를 유지한다.
- 좁은 화면은 한 열 카드, 여백 축소, 모델명 자연 줄바꿈으로 처리한다. 모델명과 가격의 좌우 관계는 유지하고 긴 모델 ID·큰 가격도 잘리지 않게 한다. 가격 조회·모델 선택·키 보관·통계·권한은 변경하지 않는다.
- 320/375/768px 및 데스크톱 폭의 모의 설정 화면에서 가격/모델명 겹침·가로 넘침·선택 동작·미확인/오래된 가격을 확인한다. 라이트/다크를 확인하고 구문 검사 후 문서에 결과를 반영한다. 실제 모바일 Chrome 확장 실행 지원과 좁은 화면 레이아웃 검증은 구분한다. 유료 API 호출은 하지 않는다.

## 결과

완료. 확장/package 0.14.1. 보안 정책 schema14와 가격 조회·키 보관·모델 지원 범위를 유지했다.

- 모델명/ID/출시일·배지를 왼쪽에, 입력·출력 가격과 공통 단위를 같은 행 오른쪽에 배치했다. 1280px의 일반 카드 높이는 약 107px로 확인했다. 820px 이하 한 열, 400px 이하 여백 축소를 적용했다. 긴 이름과 ID는 생략하지 않고 줄바꿈한다.
- 입력 파랑/출력 보라색의 글자+배경을 적용했다. 대비 비율은 라이트 입력 7.50:1·출력 7.14:1, 다크 입력 8.16:1·출력 8.03:1이다. 색만으로 구분하지 않고 입출력 문구·공통 단위·가격별 접근성 설명과 크레딧 툴팁을 유지했다. 이전값의 opacity 감소를 제거해 대비가 흐려지지 않게 했다.
- 모의 브라우저의 라이트/다크 각각 320/375/768/1280px에서 34개 카드의 가로 넘침·모델명/가격 겹침이 없음을 DOM 치수로 확인했다. 320px에서 GPT·긴 Gemini 모델명/ID·선택 표시를 스크린샷으로 확인했다. 작은 $0.000056, 큰 $1,000,000,000.00, 미확인 가격도 넘침 없이 표시했다. 큰 가격에서는 모델 정보와 가격이 추가 줄바꿈된다.
- 테마 검증은 모의 페이지에서 실제 제품의 prefers-color-scheme CSS 규칙을 전환했다. OS/브라우저 사용자 설정은 변경하지 않았다. 검증용 뷰포트는 종료 시 원복한다.
- JavaScript 59개 구문·설정/권한 검사 PASS, 기존 자동 테스트 194개 PASS. 브라우저 콘솔 오류 없음. 신규 단위 테스트는 단순 배치 변경을 반복하는 형태로 추가하지 않았다. 실제 키·유료 API·모바일 기기에서의 확장 설치/실행 검증은 하지 않았다.
