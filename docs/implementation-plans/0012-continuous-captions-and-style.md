# 0012 — 연속 자막 번역과 표시 설정 (0.9.0)

## 목적과 원인

기존 UI는 시작할 때 자막을 한 번 수집하고 당시 구간 번역이 끝나면 작업을 종료한다. 이후 로드된 구간은 다시 버튼을 눌러야 하며 이미 완료된 동일 scope에서는 수집도 건너뛰는 문제가 있다.

## 구현 계획 (코드 변경 전)

- 번역을 명시적인 ON/OFF로 변경한다. 최초 상태는 OFF, 사용자가 ON하면 작업 종료까지 주기적으로 새 자막을 수집하고 미번역 문장만 기존 구조화 API에 보낸다. OFF는 타이머와 진행 중 번역을 취소하고 표시를 숨긴다. 완료 결과는 같은 작업에서 ON할 때 재사용한다. 별도의 표시 ON/OFF는 혼동을 줄이기 위해 제거한다.
- 5초 주기 확인, 탐색 후 확인을 수행하되 실제 자막 재수집은 최소 10초 간격, 번역은 최소 2.2초 간격으로 직렬화한다. 읽기/번역이 끝나기 전에 같은 작업을 중복 실행하지 않는다. 현재 위치 이후 미번역 구간을 우선 처리하고 이전 로딩 구간과 새 구간을 합친다. 타임코드가 같고 문장이 수정되면 새 문장을 적용한다. 결과 캐시는 텍스트 기준으로 재연결하여 응답 ID 재사용으로 다른 번역이 섞이지 않게 한다.
- 일시적 실패는 제한된 간격 증가(5~60초)로 자동 재시도한다. 인증·동의·설정 변경·세션 예산·형식 오류 등 조치가 필요한 실패는 OFF 및 안내한다. 기존 Google 분당/세션 예산은 유지한다. 수집 실패 중에도 보유한 자막의 미번역 처리를 계속할 수 있게 한다.
- ON 상태는 현재 영상/문서에만 한정한다. 언어·원문 트랙 변경, 닫기, 영상 이동은 이전 작업을 무효화한다. 영상 이동 뒤 자동 외부 전송을 시작하지 않는다. 광고·숨겨진 탭은 확인을 잠시 쉬고 복귀 시 재개한다.
- 자막 세부 설정: 배경 불투명도, 글자 불투명도, 서체(기기 내 기본/고딕/명조/고정폭), 글씨 크기, 세로 위치, 가로 정렬, 기본값 복원. 미리보기를 제공하고 변경 즉시 표시한다. 외부 폰트/자원을 내려받지 않는다.
- 표시 설정만 trusted local에 저장하여 재열기/브라우저 재시작 후 유지한다. ON 여부·원문·번역은 저장하지 않는다. 설정 값/서체/범위를 background에서도 검증하고 API 키 저장 공간은 읽지 않는다.

## 변경 대상

video-content.js, video-core.js, 별도 연속 처리 컨트롤러/표시 설정 모듈, broker.mjs, 주입 목록, 버전/보안 정책, 테스트 fixture 및 기획·구조·트러블슈팅 문서.

## 검증

- 가상 시계 자동 테스트로 늦게 로드되는 구간 수집/번역, 중복 요청 방지, 시간/문장 갱신, OFF/취소/늦은 응답, transient 오류 재시도·한도/설정 오류 중지, 재시작 시 완료 결과 재사용을 확인한다.
- 저장 설정의 허용 범위·trusted access·부적합 값 거절·비밀정보 비노출 테스트.
- 브라우저에서 실제 ON 유지 중 추가 구간 자동 번역, OFF 후 요청 없음, 서체/크기/불투명도/위치/미리보기와 설정 복원을 확인한다. 실제 키와 API는 사용하지 않는다.
- 기존 자동 테스트, 구문/하네스 검사 및 문서 반영.

## 결과

- 0.9.0 구현 완료. 연속 처리를 video-session.js, 표시 값 검증/적용을 video-style.js로 분리하고 문서 grant 기반 VIDEO_STYLE_GET/SET 저장을 연결했다. 기존 키·동의·배치·예산·YouTube 수집 제한을 유지한다. 보안 정책 schema v9와 하네스를 갱신했다.
- `npm test` 103개 통과, `npm run check` JavaScript 43개/JSON/권한 검사 통과, PowerShell 하네스 통과.
- 브라우저 더미에서 ON 중 후속 구간 자동 번역(최초 2문장 + 신규 1문장), 반복 확인 중 중복 API 요청 없음, OFF 후 수집/번역 중단을 확인했다. 불투명도·서체·크기·위치·정렬 변경, 재열기/재로드 후 복원, 기본값 복원과 패널 접기 후 자막 표시를 확인했다.
- 실제 Chrome/YouTube/Google 전체 통합은 미검증이다. 실제 키를 읽거나 API를 호출하지 않았다. 제품은 계속 서버 없이 동작한다.
- 기획·전체 계획·실행 구조·보안·설치 안내·[트러블슈팅](../troubleshooting/2026-09-06-continuous-captions-and-style.md)에 반영했다.
