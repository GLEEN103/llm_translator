# 0020 — 토큰 사용 기록·통계 페이지·오늘 요약 (0.12.0)

## 구현 전 계획

- Google generateContent의 usageMetadata를 기초로 입력(prompt), 출력(candidates), 추론(thoughts), 합계(total), 캐시 입력(cached)을 별도 기록한다. 출력/추론은 분리하고 캐시는 입력에 포함되므로 합계에 중복 더하지 않는다. 근거: https://ai.google.dev/api/generate-content 및 https://ai.google.dev/gemini-api/docs/generate-content/tokens .
- 현재 텍스트 성공 응답만 usage를 반환하고 background는 버리며 이미지 조기 반환/오류 응답은 누락된다. 공급자 실제 HTTP 시도마다 시작 기록을 남기고 파싱 가능한 응답의 숫자를 출력 검증 이전에 확보한다. 취소/네트워크 실패/메타데이터 부재는 미확인으로 남긴다. 자동 재시도는 별도 실제 시도이며 캐시 재사용/ON-OFF/설정/모델 목록은 토큰 요청으로 세지 않는다.
- background 전용 tokenUsage local 레코드에 요청 시작 시 기기 날짜·공급자·정확한 모델·기능별 합산을 직렬 저장한다. 요청 임시 ID는 중복 마무리 방지용이며 키/URL/원문/영상 ID는 저장하지 않는다. 재시작/키 삭제와 독립적으로 유지한다. 최근 365일/최대 10,000 집계 행과 최대 128개 미완료 ID로 저장 크기를 제한하고 UI에 보관 범위를 표시한다.
- 시작 기록 저장 실패는 외부 요청 전에 명시적으로 실패시킨다. 완료 기록 저장 실패는 번역 결과를 버리지 않고 미확인 집계와 통계 경고로 표시한다. 기록 삭제는 통계 페이지에서 제공하고 진행 중의 삭제 이전 요청이 기록을 되살리지 않게 한다.
- 확장 팝업(도구 아이콘 클릭 시)에 오늘 입력/출력/전체·미확인 요약과 통계 보기 버튼을 둔다. API 설정에도 통계 페이지 링크를 둔다.
- 별도 statistics.html: 오늘/7일/30일/전체 보관기간, 모델/기능 필터, 입력·출력·추론·전체 카드, 일별 막대/표, 모델별 표, 시도/미확인 수, 새로고침·삭제. 메타데이터 누락값을 확정 0으로 오해하지 않게 알려진 합산과 미확인 수를 표시한다. 최초 설치 전 사용량/타 기기의 사용량/청구금액은 조회하지 않는다.
- 조회/삭제는 정확한 확장 popup/statistics 페이지만 허용한다. 원격 폰트/라이브러리/네트워크 통계 서비스/서버/추가 권한은 사용하지 않는다. 정책 schema v12로 기록 종류를 반영한다.

## 검증

provider 성공/이미지/잘못된 번역/재시도/실패/취소별 이벤트, 통계 동시 저장·일자 경계·누락값·재시작·삭제·민감정보 제외·권한 경계를 Node로 검증한다. 실제 UI는 더미 통계로 팝업/통계 페이지의 카드·필터·빈 상태·삭제를 브라우저에서 검증한다. 구문·하네스 후 사용법/보안/구조/기획·트러블슈팅에 반영한다. 실제 키·외부 번역 호출은 하지 않는다.

## 결과

완료. 확장/package 0.12.0, 보안 schema v12. `usage.mjs` 직렬 저장과 Google 시도별 훅을 연결하고 `statistics.html` 별도 페이지, API 설정 링크, 팝업 오늘 요약을 구현했다. 캐시 재사용 제외·오류 출력/이미지/재시도 집계·삭제 이전 늦은 완료 무시를 검증했다.

Node 139개 통과(신규 15개 및 기존 자막 분류 보강), JavaScript 54개·JSON·진입점·권한 검사와 하네스 통과. 모의 UI에서 오늘/전체 기간·모델/기능 필터·미확인·빈 상태·삭제·조회 오류/복구·팝업 이동·340px 가로 overflow 없음·다크테마 대비를 확인했다. 상세 수치는 [트러블슈팅 기록](../troubleshooting/2026-09-06-token-usage-statistics.md)에 남겼다.

실제 API/키는 사용하지 않았다. 설치된 Chrome/Google 계정에서의 통합 검증은 남아 있다. 응답 미수신/worker 종료/완료 기록 저장 실패는 실제 사용량을 복원할 수 없어 미확인으로 남으며 계정의 청구/전체 사용량을 보장하지 않는다. 숫자는 안전 정수 상한에서 제한한다. 추가 제품 서버·권한·외부 라이브러리는 없다.
