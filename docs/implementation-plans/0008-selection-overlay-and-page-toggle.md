# 0008 — 선택 영역 오버레이와 본문 번역 ON/OFF

상태: 구현·검증·관련 문서 반영 완료 (0.6.0).

## 목적·범위

- 선택 번역은 우클릭 실행 즉시 원문 위치에 작은 오버레이로 진행 상태와 번역문을 표시한다. 별도 번역 패널을 열지 않으며 원문 DOM을 수정하지 않는다. 기본 목표 언어는 한국어이며 본문에서 선택한 언어가 있으면 따른다.
- 실제 선택 Range를 우선 사용하고, 메뉴로 선택이 사라졌으면 이전 contextmenu 시점 Range 또는 유일하게 일치하는 가시 원문을 사용한다. 중복 등으로 위치를 확정하지 못하면 번역 요청 없이 다시 선택하도록 안내한다.
- 스크롤·창 크기 변경에 맞춰 원문 위치를 따라간다. 선택 원문 변경/삭제 시 닫고 늦은 응답을 적용하지 않는다. 닫기·재시도 제공, HTML 출력 금지.
- 본문 번역 결과는 ON/OFF로 원문과 번역문을 반복 전환한다. 토글은 API를 호출하지 않고, OFF 상태의 진행 중 응답도 화면에 적용하지 않는다. UI 닫기는 번역 상태/결과를 삭제하지 않고 작은 다시 열기 버튼으로 축소한다.
- 같은 탭의 마지막 번역 페이지 결과를 trusted session에 보관한다. 같은 URL·모델 설정 버전·언어·원문일 때 새로고침 후에도 재사용하며 탭 종료 시 삭제한다. 다른 페이지/언어/모델의 새 번역은 캐시를 교체한다. 저장 용량 초과/실패 시 현재 문서 메모리는 유지하고 재로드 재사용 불가를 안내한다.

## 변경 대상·설계

- `dom.js`: 선택 Range 확인/추적, 안전한 본문 재적용.
- `content.js`: 선택 오버레이와 본문 상태 분리, 자동 선택 번역, 본문 토글·축소·다시 열기·새 번역, 취소/지연 응답 처리.
- `broker.mjs`, `background.js`, 새 캐시 모듈: 탭별 응답 캐시, 문서 grant 검증, 탭 닫기와 탐색 수명 분리. 캐시 결과도 기존 응답 계약 검증.
- fixture, 자동 테스트, 버전 0.6.0, 사용법/구조/보안/트러블슈팅 문서.

## 보안 영향

- 기존 키 저장·전송 동의 정책 유지. 동의 후 사용자가 누른 우클릭 메뉴 자체가 선택 원문 전송 실행이다.
- 본문 원문/번역문은 사용자 요청에 따라 trusted session에 한시 보관한다. local/sync/로그에 저장하지 않고 다른 탭에 반환하지 않는다. 선택 번역은 캐시에 저장하지 않는다.
- 캐시는 탭별 최대 500개 구간, 원문+번역 합계 1,000,000자까지. 설정 변경 시 재사용 차단. 종료와 저장을 직렬화해 닫힌 탭의 늦은 응답이 캐시를 다시 생성하지 않게 한다.
- 서버와 새 권한을 추가하지 않는다. 외부 실제 API/실제 사용자 키를 사용하지 않는 모의 검증을 수행한다.

## 검증

- Node: 탭/문서/설정/언어/URL 격리, 캐시 재사용·재생성·종료 삭제, 늦은 응답, 선택 번역 캐시 제외, 용량 경계.
- 브라우저: 원문 위치 오버레이/원문 불변/스크롤 추적/선택 소실·변경, 본문 ON/OFF 반복·OFF 중 응답·축소·재열기·부분 번역 병행, 페이지 수정 보호, 기존 레이아웃 회귀.
- 구문/하네스 검사. 실제 Chrome 메뉴와 실제 Google API 연결 검증 여부를 분리해서 기록한다.

## 구현 결과

- 선택은 원문 위치 오버레이에서 자동 실행하며 결과/오류/재시도/닫기를 제공한다. live/저장 Range와 유일한 가시 문자열 복원을 사용한다. 메뉴 공백 정규화 문제는 원본 offset 매핑으로 보완했다.
- 본문 ON/OFF·진행 중 OFF·패널 축소·재열기·새 번역을 구현하고 선택 state와 분리했다. 같은 문서 grant를 재사용한다.
- trusted session 탭 캐시를 추가했다. 부분 hit는 누락 구간만 전송하고 캐시 결과에도 응답 계약을 검증한다. 선택 캐시는 제외하고 탭 종료에서 삭제한다. 저장 실패는 유효한 번역을 버리지 않고 한계를 안내한다.
- 전체 보안 설정 schema v5, API 키 저장 정책 v4 유지. 새 권한/서버/외부 패키지는 추가하지 않았다.

## 검증 결과와 남은 범위

- `npm test`: 58개 통과.
- `npm run check`: JavaScript 26개·JSON·진입점·권한 범위 통과. `tools/verify-harness.ps1`: 구조·보안 설정 schema v5 검사 통과, 비밀 파일 열람 없음.
- 브라우저 DOM fixture: 40개 자동 검사 통과. 모의 UI에서 오버레이 위치/원문 불변/스크롤·화면 밖 숨김/변경 시 제거, 본문 토글·축소·재열기, OFF 중 지연 응답, 본문과 선택 작업 공존, 실패/재시도를 확인했다.
