# 토큰 기록·통계 검증 — 0.12.0

관련 계획: [0020](../implementation-plans/0020-token-usage-statistics.md).

## 확인한 원인과 변경

이전 Google adapter는 정상 텍스트 번역에서만 usage를 반환했고 broker가 이를 버렸다. 이미지 조기 반환, 파싱 실패, 재시도에는 기록 지점이 없었다. 실제 HTTP 시도 전/후 저장 훅을 붙이고 번역 출력 검증 전에 숫자 metadata를 확보했다. 시작/완료/삭제를 직렬화하고 완료 ID를 한 번만 소비한다. 본문 캐시에서 끝나는 요청에는 provider 훅이 실행되지 않는다.

## 사용자에게 표시되는 상태

- 0 또는 기록 없음: 설치/업데이트 이전 사용량은 역조회하지 않는다. 선택한 날짜·모델·기능에 요청이 없는지 확인한다. 번역 재표시는 새 요청이 아니다.
- `*` 또는 `—`: 해당 항목을 알려주지 않은 요청이 있다. 실패/취소의 실제 사용량이 없다는 뜻이 아니다. 추론·캐시 항목을 생략하는 응답도 있을 수 있다.
- 기록 저장 실패: 시작 기록을 저장하지 못하면 새 HTTP 호출 전에 중단한다. 브라우저 저장 공간을 확인한다. 완료 저장 실패는 결과를 버리지 않고 미확인 요청과 경고를 남긴다. worker 재시작 후 경고 문구는 사라질 수 있어도 미확인 요청 수는 유지된다.
- 오늘과 전체 차이: 요청 시작 시 기기 날짜로 묶는다. 자정 이후 도착한 응답도 전날 시작 요청이면 전날 집계에 반영한다. 다른 기기/계정 도구에서 사용한 양은 이 기록에 없다.

## 검증 결과

- Node 139개 통과. 신규 15개 테스트와 기존 자막 테스트 보강: 동시 32건·중복 완료·재시작·자정/연말/윤일·보관 한도·누락값·삭제 중 늦은 완료·저장 실패·민감 필드 제거, 오류 출력의 사용량·HTTP 재시도·네트워크/취소, 본문 캐시 제외·이미지 조기 반환·자막 분류·키 삭제 독립성·UI 송신자 권한.
- 구문/구성 검사 54개 JavaScript 및 JSON·확장 진입점·권한 통과. 보안 schema v12 하네스 통과.
- 모의 브라우저: 오늘 입력 2,630 / 출력 500* / 전체 3,200*, 30일 전체 4,450*, 전체 보관기간 16,950* 확인. 모델+이미지 필터는 입력 600 / 출력 100 / 추론 0 / 전체 700. 빈 조합은 요청 없음, 삭제 후 0건, 조회 실패 안내와 복구 확인.
- 팝업 340×600 검증: 오늘 요약이 상단 436px 안에 표시되고 가로 overflow 없음. 통계 링크 이동, 작은 화면 카드/표 컨테이너, 다크테마 대비 보정 확인. 테스트 페이지 콘솔 오류 없음.
- 삭제 확인은 브라우저 native confirm을 사용한다. 자동화의 최초 dialog 연결에서 시간 초과가 있었으나 재연결 후 모의 기록 삭제·0건 화면을 확인했다.
- 실제 API 키/번역 요청 없이 더미 데이터만 사용했다. 설치된 Chrome MV3 UI·실제 계정별 usageMetadata 통합은 별도 검증이 남아 있다.
