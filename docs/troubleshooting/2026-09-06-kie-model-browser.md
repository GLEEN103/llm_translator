# kie.ai 모델 탐색과 토큰 축약 — 0.13.0

구현 범위는 [0021](../implementation-plans/0021-kie-provider-and-model-browser.md)을 따른다. 초기 10개 모델의 텍스트·YouTube 자막을 지원하며 이미지 번역은 Google에 유지한다.

## 확인된 문제와 수정

kie.ai는 모델별로 chat completions, Claude messages, GPT responses의 요청·완료·usage 형식이 다르다. 하나의 Google/OpenAI 호환 요청으로 모두 처리하지 않고 확인한 고정 경로별 어댑터를 사용한다. 도구 호출·불완전 출력·잘못된 JSON/구간 ID는 적용하지 않는다.

모의 통계 화면에서 모델 표가 여러 날짜의 합계를 마지막 날짜로 덮어쓰고 kie.ai 모델에 Google 이름을 표시했다. 그룹 존재 검사와 삽입에 다른 키를 사용한 것이 원인이었다. `groupUsage`가 공급자+정확한 모델 ID로 합산하도록 통일했다. 날짜·기능이 다른 Google 3건의 전체 4,450과 kie.ai 별도 행을 화면에서 확인했고 회귀 테스트를 추가했다.

## 사용 중 안내

- 모델 목록은 공개 공식 문서와 구현한 경로의 교집합이다. 목록 성공은 API 키 유효성·잔액·계정 권한을 보장하지 않는다. 인증/잔액 오류는 해당 공급자 계정에서 확인한다. 키 원문을 오류 보고에 첨부하지 않는다.
- 목록에 없는 모델은 현재 미지원이다. 새 경로를 사용자 입력으로 추가하거나 다른 모델로 자동 전송하지 않는다.
- 공급자 선택은 설정 화면의 보기 전환이다. 모델을 저장하거나 저장 모델 사용을 눌러야 활성 공급자가 바뀐다. 같은 이름의 Google/kie.ai 모델도 키를 따로 저장한다.
- kie.ai에서 이미지 메뉴를 실행하면 캡처·API 호출 전에 미지원 안내를 표시한다. 이미지 번역에는 저장된 Google 멀티모달 모델을 활성화한다.
- 3.4M 같은 값은 표시 반올림이다. 마우스를 올리면 정확한 수치를 확인한다. `*`는 일부 미확인, `—`는 확인값 없음이며 저장된 숫자는 축약하지 않는다.

## 검증

자동 테스트 157개, JavaScript 57개 구문·설정 검사, 보안 하네스를 통과했다. 모의 브라우저의 카드 검색/필터/선택/저장·공급자 전환·기존 키 유지·통계 필터·정확값 툴팁과 콘솔 오류 없음을 확인했다. 실제 공급자 호출·키 사용은 하지 않았다. 서비스별 응답 변화·계정 권한·실제 지연과 품질은 미검증이다.
