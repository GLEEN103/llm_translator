# 형식 오류 재시도와 영상 번역 재사용

0.18.0에서는 JSON 문법, 스키마, 번역 구간 ID 오류가 발생하면 최초 요청 후 최대 3회 재시도한다. 재시도 사이는 5초이고 확장의 동시 5개/최근 60초 60회 제한과 토큰·문자 예산에 포함된다. 제한 대기는 추가 형식 실패로 세지 않는다.

4번째 형식 검증도 실패하면 해당 묶음만 오류로 남긴다. 자막은 ON을 유지하고 오류 시각의 자막에는 `[번역 오류]`가 표시된다. 패널의 **번역 오류 로그**에서 코드와 재시도 횟수를 확인하고 **실패 구간 재시도**로 다시 시도할 수 있다. 본문/부분은 **남은 구간 재시도**, 이미지는 **재시도**를 사용한다. 로그는 최대 100행이며 원문·키·공급자 원시 응답은 기록하지 않는다.

타임아웃·연결 단절·거절·불완전 생성·인증/예산 오류는 형식 오류가 아니므로 이 자동 재시도 대상에서 제외한다. 기존 공급자별 중단/오류 처리는 유지한다. 키를 바꿀 필요가 없는 형식 오류 때문에 API 키를 삭제하거나 노출하지 않는다.

영상 번역은 성공한 묶음부터 기기에 저장한다. 오류·뒤로가기·새로고침·브라우저 재시작 뒤 같은 영상·공급자·모델·언어·원문이라면 API 호출 없이 재사용한다. YouTube 자막 타이밍은 현재 페이지에서 다시 읽어야 한다. 자막 원문이 수정되거나 언어·모델을 바꾸면 해당 구간을 새로 번역한다.

**API 설정 → 저장된 영상 번역**에서 보관 건수/용량을 확인하고 전체 삭제한다. 최근 최대 30개 영상/총 4 MiB이며 초과하면 오래 사용하지 않은 영상부터 정리한다. 저장 실패/용량 축소는 자막 패널에 안내하고 현재 화면의 성공 결과는 유지한다. API 키 삭제와 영상 캐시 삭제는 독립적이다. 현재 열려 있는 패널의 메모리 결과는 캐시 전체 삭제 후에도 페이지를 닫을 때까지 표시될 수 있다.
