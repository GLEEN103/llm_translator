# 자막 패널 재열기·닫기 변경 — 0.11.1

사용자가 UI 숨김 후 페이지 자막 번역 버튼으로 재열기 실패를 보고했다. 기존 구현은 표시 복원에도 background의 설정/문서 검사와 재주입을 거쳤다. 모의 환경에서는 열기 응답 오류를 켜면 기존 경로가 실패하며, 사용자 실제 환경의 구체적인 실패 지점은 확인하지 못했다.

현재 영상에 이미 존재하는 패널은 launcher의 trusted 클릭에서 isolated world의 복원 함수로 바로 표시한다. 이 경로는 ON/결과를 유지하고 worker 열기 응답에 의존하지 않는다. 다른 영상/분리된 video/없는 패널은 복원하지 않고 기존 background 진입을 사용한다. 기존 UI 숨기기는 닫기로 이름을 바꾸었고 종료용 닫기는 제거했다. 번역 중지는 OFF를 사용한다.

브라우저 모의 검증에서 일반 영상의 ON → 닫기 → 열기 오류 → 페이지 버튼 복원, 무응답 상태에서 반복 복원을 확인했다. Shorts도 같은 무응답 재열기에서 ON/완료 문장·요청 1회·취소 0회를 유지했다. 패널·자막 숨김 후 재열기, 영상 변경 시 기존 패널 제거와 새 OFF 작업도 확인했다. 헤더에는 접기·닫기만 표시한다.

Node 120/120 PASS, JS 48개 구문/JSON/manifest 검사 PASS. 모의 키/응답만 사용했으며 실제 API 호출은 0회다. 실제 설치된 Chrome/YouTube/Google 통합 검증은 미실시다. 업데이트 후 확장과 페이지를 새로고침한다. [구현계획](../implementation-plans/0017-caption-panel-reopen.md).
