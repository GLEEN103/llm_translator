# 2026-09-06 — YouTube 자막 읽기와 오버레이

관련 구현계획: [0010](../implementation-plans/0010-youtube-caption-translation.md).

## 자막 수집 경로와 확인된 제약

YouTube Data API의 captions.download는 영상 편집 권한을 요구한다. 일반 시청자가 Google AI Studio 키만으로 다른 영상 자막을 다운로드하는 API로 사용할 수 없다. 로컬 서버를 추가해도 이 권한 제약이 해결되는 것은 아니다. 구현은 현재 페이지 플레이어가 제공하는 트랙과 동일 출처 timedtext 응답을 사용한다.

이는 YouTube가 보장하는 외부용 자막 API가 아니다. 자막 미제공, 플레이어 변경, 서명/권한/페이지 CSP에 따른 수집 실패를 구별하여 안내한다. 자동자막이 아직 생성되지 않았거나 제공되지 않는 경우 음성 인식으로 자동 대체하지 않는다. 사용자는 YouTube 자막을 켜서 제공 여부를 확인하고 페이지를 새로고침하여 확장 버튼에서 다시 실행한다.

허가받은 공개 영상 `jNQXAC9IVRw`, `M7lc1UVf-VE`를 in-app 테스트 브라우저에서 열었다. 두 페이지에서 플레이어 자막 컨트롤이 “자막 사용 불가”로 표시되어 실제 자막 다운로드의 성공 증거를 얻지 못했다. 이것만으로 영상에 원래 자막이 없다고 단정하지 않는다. Chrome에 확장을 로드한 실제 동작과 Google 실제 API 연동은 미검증이다. 저장된 실제 API 키는 열람하거나 사용하지 않았다.

## 타이밍/취소

- 일반 자막의 겹침과 빈 구간, 자동자막 append/교체 시간을 보존한다. 자막 타임코드를 모델에 맡기지 않고 `video.currentTime`으로 찾는다.
- API 응답이 늦은 경우 현재 cue의 번역이 완성되지 않으면 표시하지 않는다. 먼 곳으로 탐색하면 다음 요청부터 그 위치 이후를 우선한다. 필요하면 일시정지 후 번역 준비를 기다릴 수 있다.
- 중지/닫기/영상 이동 시 작업 generation을 변경하여 늦게 도착한 응답을 무시한다. 완료된 자막은 중지 때 유지하고 닫기/이동 때 삭제한다.
- 광고·seeking·미디어 준비 전·종료·PIP에서는 숨긴다. YouTube 플레이어 전체화면은 오버레이 host를 전체화면 요소 안으로 이동한다.

## 검증 결과

- Node 자동 테스트 84개 통과. 기존 72개와 자막 파싱·시간 검색·배치/중복 제거·URL/문서/동의 경계·API 전송 최소화·실패 검증 12개.
- JavaScript 37개 및 JSON·권한/CSP 검사 통과. 하네스 schema v7 검사 통과.
- 기존 브라우저 자동 검사 50개 통과: 텍스트 DOM 40개, 이미지 처리 10개.
- 신규 로컬 브라우저 상호작용 검증: 12초 기기 생성 무음 미디어의 실제 HTMLVideoElement 재생 시계, 제작자/자동 생성 자막 선택, 한국어/일본어 전환, 중복 포함 cue 3개를 2문장/1요청으로 처리, 1초/4초 탐색, 8초 빈 구간, ON/OFF 무호출, 일시정지·2배속, 전체화면, 광고 숨김, 패널 접기/닫기, 오류/재시도, 지연 응답 중지 후 무시, 영상 이동 정리, 자막 미제공 안내를 확인했다. 이 검증은 모의 번역/모의 YouTube 트랙을 사용하며 실제 영상 서비스 통합 테스트를 대신하지 않는다.
- 응답의 `<b>` 문자열이 HTML로 실행되지 않고 그대로 보이는 것을 확인했다.

## 남은 검증

실제 Chrome에서 제작자 자막과 자동자막을 각각 제공하는 영상으로 수집·번역을 확인해야 한다. Google API 사용 검증은 사용자 키 사용·자막 전송 허가를 받은 상황에서 수행한다. Shorts·임베드·라이브·PIP 지원은 이번 범위에 포함되지 않는다.
