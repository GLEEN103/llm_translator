# Kie HTTP 500 / 오류 코드 524 추적 (0.14.4)

## 제공 자료의 확인 결과

사용자가 제공한 요청 매개변수 첨부 한 건을 로컬에서 검증했다. 원문·계정/작업 식별자는 이 문서나 테스트에 복제하지 않는다.

- 외부 JSON과 messages 안의 입력 JSON이 모두 파싱됐다. 기존 validateRequest 검증도 통과했다.
- 자막 64개, 본문 합계 2,376자, 최장 구간 40자, 고유 ID 64개다. 이는 확장 제한 64개/12,000자 이내다. 공급자 모델의 성능/처리 시간 한도를 검증한 것은 아니다.
- 스키마의 minItems/maxItems는 64이며 ID enum이 실제 입력과 일치한다. 확장이 생성한 필드와 첨부 params의 해당 필드가 일치한다.
- model/stream_options/userId는 현재 확장 생성본에는 없다. 중개 단계의 추가 필드로 보이지만 어느 단계에서 추가했는지는 확인하지 못했다. 임의로 제거할 클라이언트 필드로 취급하지 않는다.
- 첨부에는 오류 응답이 없고 사용자가 후속으로 코드 524를 알려줬다. HTTP 상태 자체가 524인지, HTTP 500 내부/대시보드의 오류 코드인지 구분되지 않는다.

## 524 해석과 진단 한계

[Cloudflare 공식 524 안내](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)는 원본 서버에 연결했지만 제한 시간 내 응답을 받지 못한 경우를 설명한다. 문서의 기본 읽기 제한은 125초이며 쓰기 제한 30초 초과로도 발생할 수 있다(2026-09-07 확인). Kie의 실제 제한 시간이나 이 요청이 어느 연결에서 지연됐는지는 알 수 없다.

따라서 이번 524는 중개/공급자 시간 초과 가능성을 가리킨다. 요청 JSON 문법 오류나 strict 스키마 미지원의 증거로 삼지 않는다. 스키마 처리가 지연에 영향을 줬는지, 모델 생성이 느렸는지, 서버가 과부하였는지도 별도 측정이 필요하다. 원인 추정만으로 스키마·경로·배치 크기를 다시 바꾸지 않았다.

확장은 별도로 기본 25초 후 요청을 취소한다. 이는 공급자 524와 다른 제한이다. 확장이 먼저 기다리기를 끝내도 서버의 처리/과금 취소가 보장되지 않아, Kie 기록에 나중의 오류가 남는 상황은 가능하지만 해당 사건에서 실제로 발생했다고 확정하지 않는다.

## 수정한 확장 동작

기존에는 HTTP 500/524를 PROVIDER_UNAVAILABLE로, 클라이언트 제한을 PROVIDER_TIMEOUT으로 처리했다. 두 코드 모두 자막 ON 세션에서 재시도되므로 같은 요청을 반복할 수 있었다.

0.14.4부터 다음 세 코드는 자막 OFF로 종료한다.

| 코드 | 판단 근거 |
|---|---|
| KIE_HTTP_500 | 실제 HTTP 500. 내부 원인은 미확정 |
| KIE_UPSTREAM_524 | 실제 HTTP 524 또는 HTTP 500 본문의 code/error.code가 정확한 숫자/문자열 524 |
| KIE_REQUEST_TIMEOUT | 확장 자체 Kie 요청 대기 제한 초과 |

오류 메시지/HTML에서 숫자만 찾아 원인을 추측하지 않는다. usage가 읽히면 숫자 집계는 유지하고 원시 오류는 노출·기록하지 않는다. 503/429의 기존 정책과 Google 동작은 유지한다. 스키마·기존 배치·키·권한·동의 정책은 바꾸지 않았다.

## 검증과 남은 확인

전체 테스트 208개 PASS, JavaScript 59개/JSON/권한 검사 PASS, 보안 하네스 PASS. HTTP 500/524 모의 통합에서 60초 후 요청 1회·세션 OFF·결과 미적용·타이머 0을 확인했다. 실제 유료 API 검증이나 서버 지연 해결 검증은 하지 않았다.

공급자 원인 확인에는 같은 실패 건의 정확한 오류 설명, 요청 시작부터 실패까지 경과 시간, 공급자 내부 처리 기록이 필요하다. Kie 문의 시 해당 실패 건을 참조할 수 있으나 에이전트가 외부 메시지를 보내지는 않는다. 0.14.4를 적용하면 확장과 YouTube를 새로고침해야 새 오류 분류가 적용된다. 업데이트 후에도 공급자 시간 초과 자체가 해결되는 것은 아니다.
