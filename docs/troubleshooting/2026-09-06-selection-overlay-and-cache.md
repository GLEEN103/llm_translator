# 선택 오버레이·본문 결과 유지 검증

## 변경 전 증상과 원인

- 선택 번역이 화면 모서리의 공통 번역 패널에 표시되어 선택한 원문과 위치가 분리됐다. 선택 문자열만 보관하고 Range 위치를 사용하지 않았다.
- 본문 패널을 닫거나 다른 번역을 열면 공통 current state를 dispose하면서 원문 복원·번역 결과 삭제가 함께 실행됐다. ON/OFF 상태와 UI 수명이 분리되지 않았다.
- 검증 중, 번역된 인라인 요소 사이의 원본 공백과 브라우저 메뉴 selectionText의 정규화된 공백이 달라 위치 복원이 실패했다.

## 해결

- 선택과 본문 state 분리. 선택은 즉시 번역하는 원문 위치 오버레이, 본문은 ON/OFF와 패널 축소/재열기 제공.
- 실제 Range 또는 모호하지 않은 가시 텍스트로 위치 복원. 공백을 정규화하되 원래 문자 offset을 매핑한다. 원문 변경/삭제는 Range 스냅샷으로 검출하고 늦은 응답을 무시한다.
- 본문 결과는 탭별 trusted session에 임시 저장하고 같은 URL·설정·언어·원문을 재사용한다. 탭 닫기/저장을 직렬화하여 종료 후 재저장을 막는다. 선택은 캐시 제외.

## 검증 결과

- Node 테스트 58개 통과: 캐시 재사용·worker 재생성·문서 재로드 모형·탭 종료 삭제, URL/모델/언어/탭/문서 격리, 설정 변경, 부분 cache hit, 선택 캐시 제외, 늦은 응답, 저장 실패/용량 경계 포함.
- 구문/구성 검사: JavaScript 26개·JSON·확장 진입점·권한 범위 통과. 하네스 구조·보안 설정 schema v5 검사 통과.
- 브라우저 DOM 자동 검사 40개 통과: 기존 레이아웃·HTML 텍스트 처리, 유일한 선택 위치 복원·중복 거절·공백 정규화·원문 변경, 반복 적용/복원 포함.
- 모의 브라우저에서 54개 본문 구간(중복 제외 53개)을 한 요청으로 처리하고 ON/OFF·패널 축소·재열기에 추가 요청이 없음을 확인했다.
- 지연 응답 중 OFF 전환 → 완료 뒤에도 원문 유지 → 재열기에서 54/54 완료 → ON 전환 시 저장 결과 표시를 확인했다.
- 본문 결과를 유지한 채 선택 오버레이 실패/재시도, 원문 불변, 스크롤 이동 및 화면 밖 숨김, 원문 수정 후 오버레이 제거를 확인했다. 화면 아래쪽에서는 결과가 화면 안에 들어오도록 위치를 보정한다.

## 한계

실제 Chrome 설치 메뉴, 실제 계정 API, 브라우저 재시작·탭 종료 이벤트는 실제 Chrome 확장에서 검증하지 않았다. 탭 수명/worker 복구는 모의 Chrome API를 사용한 Node 검사다. 브라우저 fixture는 모의 번역이며 확장 저장소는 사용하지 않는다. 동적 사이트·transform/top-layer·복잡한 다중 블록 선택의 위치는 추가 호환 검증 대상이다. 위치를 확정하지 못하면 전송하지 않는다.

본문 캐시는 마지막 페이지/설정 조합만 보관하며 탭별·브라우저 전체 저장소 한도가 있다. 저장 실패는 UI에 안내한다. 영구 보관이나 확장 재로드 후 복원을 보장하지 않는다.
