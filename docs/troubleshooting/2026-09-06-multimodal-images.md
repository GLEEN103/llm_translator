# 멀티모달 이미지 번역 — 구현·검증 기록

관련 계획: [0009](../implementation-plans/0009-multimodal-image-translation.md). 버전 0.7.0.

## 동작과 해결 과정

이미지 우클릭 메뉴 → 로드된 img 확인 → 기기 내 재인코딩/축소 → Google 멀티모달 요청 → 인식 원문과 번역문을 이미지 위 오버레이로 표시한다. 기존 온디바이스 OCR 후 텍스트 번역 계획은 사용자 요청으로 변경했다.

CORS 차단 이미지에는 captureVisibleTab과 기기 내 crop을 사용한다. 처음 겹침 검사를 구현할 때 숨겨진 details 자식과 화면 전체를 차지하는 투명 컨테이너까지 겹친 것으로 판정하는 문제가 있었다. 요소 교차점 hit test와 실제 페인팅 여부를 결합해 보완했고, 2px 크기의 실제 가림 요소는 계속 차단하도록 검사했다.

## 증상별 안내

| 증상 | 조치 |
| --- | --- |
| 이미지 번역 메뉴가 없음 | 확장을 0.7.0으로 새로고침하고 대상 페이지도 새로고침. HTTP(S) 메인 문서 이미지에서 우클릭 |
| 동의 화면이 열림 | 이미지 전송이 포함된 새 버전 동의 후 이미지를 다시 우클릭 |
| 이미지 대상을 확정하지 못함 | 이미지 로드를 기다리고 다시 우클릭. 같은 src 중복은 두 번째 클릭에서 대상 기록 사용 |
| 화면 안에 표시하라는 안내 | 이미지 전체를 화면에 넣고 가리는 패널을 닫기. 잘림/회전/복잡한 합성/다수 요소 페이지는 캡처 불가일 수 있음 |
| 선택 모델이 이미지 입력/구조화 응답을 지원하지 않음 | API 설정에서 지원하는 모델을 명시적으로 활성화하고 다시 실행. 다른 키/모델로 자동 전환하지 않음 |
| 문자 없음 | 모델이 읽을 수 있는 문자를 찾지 못함. 문자 크기·해상도 확인. 없는 원문을 임의로 생성하지 않도록 요청함 |
| 오버레이가 사라짐 | 원본 src/크기가 바뀌거나 img가 제거되면 취소·제거하는 동작. 다시 우클릭 |
| 작업 토큰 만료 | worker 재생성·새 이미지 작업·문서 이동 후 발생 가능. 이미지를 다시 우클릭 |
| 이미지 요청 50회 한도 | 세션 이미지 예산 도달. 자동/수동 재시도도 포함. 키를 변경해도 예산 초기화하지 않음 |

## 검증 범위

- `npm test` 72개, 구문/구성 JavaScript 32개 및 하네스 보안 설정 검사 통과.
- Node 모의 검사: 이미지 입력/응답 규격, 픽셀만 담는 구조화 payload, 메뉴/문서/토큰/동의/모델 검증, 이미지 예산·취소, 캡처 탭 전환·좌표 변경 차단.
- 브라우저 이미지 자동 검사 10개: PNG 재인코딩, 원본 DOM 보존, crop geometry, 작은 가림 검출, 실제 CORS taint, 중복 src 거절, 2048px 축소, OffscreenCanvas 실제 crop 크기/주변 빨간 픽셀 제거, src 변경 감지.
- 기존 텍스트 DOM 검사 40개 회귀 통과.
- 닫은 뒤 15초 지연 응답이 도착해도 이미지 오버레이가 다시 나타나지 않았다. 본문 54구간 완료·OFF 전환에도 이미지 기능으로 인한 회귀나 추가 요청이 없었다.
- 모의 이미지 오버레이에서 한국어·일본어 목표 언어, 인식 원문 펼치기, noText, 모델 미지원 오류/재시도, HTML 문자열의 텍스트 표시, 원본 이미지 교체 시 제거를 확인했다. CORS 경로 UI는 캡처 API 응답을 모의 처리했다.

실제 Google 인식/번역 품질·계정 호출과 설치된 Chrome의 우클릭 메뉴/실제 captureVisibleTab 권한 통합은 미실행이다. 실제 사용자 이미지/키는 사용하지 않았다. 화면 캡처 테스트의 원본은 코드로 만든 공개 모의 픽셀이다. 복잡한 페이지 합성 효과·애니메이션·사이트별 동적 UI는 추가 검증 대상이다.
