# 확장 API 직접 호출 — 설정과 오류 확인

현재 제품은 확장 단독 실행이다. 서버를 실행하거나 확장 ID·연결 토큰을 등록할 필요가 없다. 모델별 키 영구 저장·출시일 정렬의 최신 기록은 [0006](../implementation-plans/0006-model-profiles-and-security.md)이다.

| 증상 | 조치 |
| --- | --- |
| 이미지 번역 문제 | [이미지 메뉴·수집·모델·캡처 오류 안내](2026-09-06-multimodal-images.md) 참고 |
| 부분 번역 버튼이 팝업에 없음 | 0.5.0부터 텍스트 선택 → 우클릭 → 선택한 텍스트 번역으로 이동 |
| 선택 번역 패널이 열리지 않음 | 0.6.0부터 우클릭 시 즉시 실행하고 원문 위치의 오버레이로 표시 |
| 원문 위치를 확인할 수 없음 | 선택이 사라지고 같은 문자열이 여러 곳에 있거나 표기 공백이 달라질 수 있음. 원문을 다시 선택하고 즉시 우클릭 |
| 본문 패널을 닫아도 번역이 남음 | 결과 보관을 위한 의도된 동작. 작은 본문 번역 열기 버튼 → 번역본 OFF로 원문 표시 |
| 새로고침 후 결과를 다시 보고 싶음 | 같은 탭에서 본문 번역 → 번역 시작. URL/모델 설정/언어/원문이 같은 저장 구간은 Google 호출 없이 복원 |
| 탭 저장 실패 안내 | 현재 문서 결과는 유지. 전체 session 용량이나 탭별 500구간·1,000,000자 한도를 넘으면 새로고침 후 재요청 가능 |
| 우클릭 메뉴가 없음 | 확장을 새로고침해 contextMenus 권한과 메뉴 등록 적용. HTTP(S) 페이지에서 텍스트 선택 필요 |
| 우클릭 후 설정 화면이 열림 | 표시된 동의/키/문서 오류를 해결한 뒤 텍스트를 다시 선택하고 실행. 원문을 자동 재전송하지 않음 |
| 본문 양식이 깨짐 | 0.5.0의 Text 노드 교체 방식으로 업데이트하고 페이지 새로고침. 번역 길이에 따른 줄바꿈/높이 변화는 가능 |
| 작은 요소마다 요청이 많음 | 0.5.0은 최대 64구간·12,000자씩 묶음. 패널의 묶음 요청 수 확인. 긴 텍스트는 크기 제한으로 여러 묶음 가능 |
| API 키·모델 설정 필요 | 키 입력 → 모델 목록 불러오기 → 리스트박스에서 선택 → 저장 |
| 저장 후에도 실제 인증 실패 | 저장은 외부 호출 검사가 아니므로 키의 유효성·모델 권한 확인 |
| 브라우저 재시작 후 키가 없음 | 0.4.0부터는 모델별로 저장하면 유지됨. 이전 세션 전용 버전에서 전환한 경우 최초 등록 필요. 다른 Chrome 프로필·확장 ID·삭제 여부 확인 |
| 저장 모델로 전환하고 싶음 | 저장된 모델별 API 키 목록에서 선택 후 저장 모델 사용. 목록 재조회·키 재입력 불필요 |
| 새 모델 저장 버튼 비활성 | 그 모델에 저장된 키가 없다면 직접 입력 후 목록 조회 필요. 다른 모델 키는 자동 복사하지 않음 |
| 설정이 변경되었다는 안내 | 본문 패널의 새 번역으로 스냅샷과 모델 설정 갱신. 선택 번역은 다시 선택하고 우클릭 |
| 키 삭제 후 작업 취소 | 의도한 동작. 이미 전송된 요청의 과금까지 취소되지는 않음 |
| Google 모델 또는 요청 오류 | 목록의 콘텐츠 생성 지원이 텍스트·JSON 출력까지 보장하지는 않음. 목록 갱신 후 다른 모델 선택 |
| 모델 조회 인증 오류·빈 목록 | 키 유효성·프로젝트 권한 확인 후 다시 조회. 기존 조회 결과로 저장할 수 없음 |
| 모델 목록이 변경되었다는 안내 | 다른 설정 창의 조회·키 변경·삭제로 목록 ID가 달라졌을 수 있음. 현재 키로 재조회 |
| 모델 날짜 미확인 | Google 목록 API는 출시일을 제공하지 않음. 공식 출시 기록 확인 후 번들 날짜 테이블 갱신 필요. 모델 번호·조회 순서로 날짜를 추측하지 않음 |
| 저장·삭제 실패 | 브라우저 저장소 상태와 사용 공간 확인 후 설정 다시 열기. 오류가 나면 성공으로 간주하지 않음 |
| 활성 모델을 삭제한 뒤 번역 불가 | 다른 저장 모델을 명시적으로 활성화. 다른 모델 키로 자동 전환하지 않음 |
| 업데이트 후 동의 요청 | 의도한 동작. 팝업·설정에서 이번 버전에 최초 1회 동의 |
| 브라우저 재시작 후 동의를 다시 묻지 않음 | 동의 버전은 local에 유지함. 반복 번역·재시도도 재동의 없음 |
| 호출 한도·문자 예산 초과 | 사용량 확인. 모델 저장이나 키 교체는 세션 예산을 초기화하지 않음 |
| 확장 업데이트 후 기존 페이지에서 오류 | 해당 웹페이지 새로고침·버전별 동의. 0.4 이후 저장한 키는 유지됨 |

키·원문·응답 본문을 채팅이나 로그에 붙여넣지 않는다. 오류 코드와 재현 조건만 기록한다. 서버 필요성을 암시하는 오류 안내가 다시 등장하면 현행 설계와 맞지 않는 회귀로 취급한다.
