# 모델 가격 카드 높이·좁은 화면 — 0.14.1

## 원인과 변경

0.14.0은 모델 정보 아래에 가격 구분선·입출력 두 줄을 추가해 모든 카드 높이가 늘어났다. 가격을 모델명과 같은 행 오른쪽에 배치하고 ID·출시일·기능 배지를 이름 아래에 묶었다. 공통 단위는 가격 아래에 한 번만 표시하고 각 가격의 접근성 설명에는 100만 토큰 단위를 유지한다.

입력은 파란색, 출력은 보라색의 대비 높은 글자·배경을 사용하며 미확인도 동일한 입출력 문구로 구분한다. 이전 가격을 흐리게 만들던 opacity는 제거하고 재확인 안내를 유지한다. 가격 갱신·모델별 키·공급자 호출은 변경하지 않았다.

## 검증

- 라이트/다크 각각 320/375/768/1280px에서 34개 카드의 가로 넘침·이름/가격 겹침 없음.
- 320px에서 긴 모델명/ID·$0.000056·$1,000,000,000.00·미확인 가격과 라디오 선택을 확인. 극단적으로 긴 정보는 줄바꿈하며 잘리지 않는다.
- 일반 데스크톱 카드 높이 약 107px. 가격 글자 대비는 모든 테마/입출력 조합에서 7:1 이상.
- JavaScript 59개 구문·설정 검사와 기존 테스트 194개 통과. 모의 브라우저 콘솔 오류 없음.
- 모바일 크기 뷰포트 검증이며 실제 모바일 Chrome 확장 설치/동작 검증은 아니다. 실제 API 키·유료 호출 없음.
