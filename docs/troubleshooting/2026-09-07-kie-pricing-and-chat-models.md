# kie.ai 가격 변경과 Chat 확대 — 0.14.0

## 요청과 근거

사용자는 Chat 모델 추가와 모델 선택 카드의 입력/출력 USD 가격, 할인·가격 변경 대응을 요청했다. [공식 가격 화면](https://kie.ai/pricing)의 공개 조회는 `POST https://api.kie.ai/client/v1/model-pricing/page`이며 Chat 행에는 모델명·공급자·입출력 구분·크레딧·USD·단위·타사 비교 가격/할인율이 있다. 실제 키와 쿠키 없이 공개 읽기를 확인했다.

## 주의할 데이터 차이와 처리

- 이름의 마침표/하이픈/공백과 대소문자가 문서의 모델 ID와 다르다. 로컬 모델 ID/표시명과 확인한 Gemini 3.1 Pro 별칭만 정규화해 일치시킨다. 캐시·tier·도구·생성 모델 행은 일반 입력/출력 가격으로 사용하지 않는다.
- 할인율은 타사 비교 정보이므로 usdPrice에 재적용하면 이중 할인이 된다. creditPrice와 공식 usdPrice 쌍을 그대로 사용해 현재 할인·환산값을 반영한다. 일부 USD는 이미 반올림된 값이므로 고정 환산율의 계산 결과와 미세하게 다를 수 있다.
- 2026-09-07 공개 조회에서 Grok 4.5 입력/출력, Claude Sonnet 4.5 출력의 creditUnit이 비어 있었다. 모델 지원은 유지하고 해당 가격만 미확인으로 표시했다. 가격표에 올바른 단위가 추가되면 다음 갱신부터 자동 표시된다.
- 문서 경로 `cluade-fable-5`/`cluade-sonnet-5`의 오자는 실제 공개 링크를 그대로 사용한다. 요청 모델 ID는 올바른 `claude-...`다. Codex는 소수점 ID와 `/api/v1/responses`, GPT는 하이픈 ID와 `/codex/v1/responses`, Grok은 `/grok/v1/responses`로 구분한다.
- 일부 공식 OpenAPI 예제에 필수 `test` 필드(정의 없음), native Gemini 응답 예제 등 복사 오류가 있다. 정의된 요청 필드와 해당 경로의 응답 스키마를 따른다. 임의 test 값·native 응답 우회 파서를 추가하지 않는다. 실제 계정 호출 호환성은 별도 검증 대상이다.

## 갱신과 장애 대응

options 전용 가격 요청은 모델 목록/키/번역과 분리된다. 5분 자동 갱신과 수동 갱신, 30초 최소 간격·중복 병합을 적용한다. 숨긴 탭/Google 화면에서는 쉬고 페이지 종료 시 타이머를 정리한다. 가격 조회는 18초·10페이지/1,000행·페이지당 512 KiB로 제한한다. 공개 API 변경·오류는 원문 오류를 노출하지 않고 이전 성공 시각+갱신 실패로 표시한다. 가격이 없으면 0달러로 추정하지 않는다. 오류가 있어도 모델 선택·저장·번역은 계속 가능하다.

## 검증 결과

자동 테스트 194개, JavaScript 59개 구문·설정·권한 검사, 하네스 PASS. 모의 응답으로 모든 34개 경로의 묶음 번역 형식과 가격 할인/환산 변경·pagination·키 없는 조회·잘못된 단위·중복 충돌·실패 복구·options 권한을 확인했다. 실제 공개 목록 34개를 읽었고 가격은 32개 모델의 양쪽, Sonnet 4.5 입력을 매칭했다.

모의 브라우저에서는 GPT 6 Astra 가격 $0.50/$1.00 → $0.25/$0.50 갱신 후 선택 유지, 조회 실패 시 이전 조회값 경고, Google 전환 시 가격 UI 숨김, Grok 계열 필터·선택과 가격 실패 중 저장 성공을 확인했다. 다크 화면의 카드 배치와 콘솔 오류 없음을 확인했다. 모든 가격은 모의 값이며 실제 유료 번역 호출·키 사용·확장 설치 통합 검증은 하지 않았다.
