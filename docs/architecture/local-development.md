# 확장 설치와 사용

0.18.0에서는 형식 오류를 최대 3회 재시도하며 실패한 자막 묶음만 오류로 남기고 ON을 유지한다. 패널의 **번역 오류 로그**와 **실패 구간 재시도**를 사용한다. 성공 영상 번역은 최근 최대 30건/4 MiB를 기기에 보관해 재방문 시 같은 모델·언어·원문에 재사용한다. **API 설정 → 저장된 영상 번역**에서 상태를 확인하거나 전체 삭제한다. 기존 캐시가 없는 업데이트 전 영상은 새로 번역해야 한다.

Chrome 112 이상에서 `C:\work\program\chrome_translator\src\extension`을 압축해제된 확장으로 로드한다. 기존 설치는 확장과 번역할 페이지를 새로고침한다. 0.10.0은 YouTube 페이지 버튼을 자동 표시하기 위해 정확한 `https://www.youtube.com/*` 사이트 권한을 추가했다. Chrome의 업데이트 권한 안내가 나오면 해당 권한을 확인한다. Node.js·로컬 서버·연결 토큰·환경변수 파일은 제품 사용에 필요 없다.

0.13.0은 `api.kie.ai`·`docs.kie.ai` 권한을 추가한다. 업데이트 후 Chrome 권한 안내를 확인하고 이번 버전의 원문 전송에 최초 1회 동의한다. Google 키는 유지된다. kie.ai는 텍스트·YouTube 자막을 지원하고 이미지 번역은 Google에서 사용한다.

## 토큰 사용 통계 (0.13.0)

확장 아이콘을 누르면 팝업 상단에서 오늘 입력·출력·전체 토큰과 요청/미확인 건수를 본다. **사용 통계 보기**로 별도 페이지를 열거나 API 설정의 **토큰 사용 통계 열기** 링크를 사용한다. 키·동의가 아직 없어도 기록 조회는 가능하다.

기간은 오늘/최근 7일/최근 30일/전체 보관기간, 공급자·모델·번역 기능은 각각 선택한다. 입력·출력·추론·전체 카드, 캐시 입력, 일별 막대·표와 모델별 표가 같은 필터로 갱신된다. 토큰은 10K, 3.4M처럼 표시하며 마우스를 올리면 정확한 정수를 확인한다. 저장·합산 원값은 유지한다. 열려 있는 동안 15초마다 갱신하며 **새로고침**으로 즉시 조회한다. **전체 통계 삭제**는 확인 후 모든 기간의 기록만 삭제한다. 키·번역 캐시에는 영향을 주지 않는다.

숫자는 확인된 합계이며 `*`는 일부 요청이 그 항목을 제공하지 않았음을, `—`는 확인된 값이 없음을 뜻한다. 요청이 없는 조건과 API가 실제로 0을 보고한 항목은 0으로 표시한다. 추론 상세가 있으면 출력에서 분리하며 상세가 없으면 출력에 포함될 수 있다. 캐시 입력은 입력에 포함한다. 전체는 공급자 보고값을 사용하며 Claude는 입력·캐시 생성/읽기·출력이 모두 확인되었을 때 합산한다. 미확인은 진행 중/중단/실패/일부 metadata 누락을 포함하므로 사용량 0을 의미하지 않는다. 브라우저가 응답을 받지 못한 요청은 공급자에서 사용되었더라도 수치를 알 수 없다.

적용 후 이 브라우저에서 시작한 번역부터 기록한다. 요청 시작 시 기기 날짜 기준으로 오늘을 구분하고 시간대 변경은 과거 날짜를 바꾸지 않는다. 최근 365일·최대 10,000개 날짜/모델/기능 집계까지 보관한다. 브라우저 재시작·확장 업데이트·키 삭제 후에도 남으며 통계 전체 삭제·확장 제거로 제거한다. 과거 사용량과 계정 전체 사용량/비용은 조회하지 않는다.

개발 UI 검증은 `node tools/browser-fixture.mjs` 실행 후 `http://127.0.0.1:43188/statistics.html` 및 `/popup-preview`를 사용한다. 이 서버는 개발 검증 전용이며 더미 토큰만 사용하고 외부 API를 호출하지 않는다. 검증 후 종료한다.

## 모델별 키 등록과 전환

0.14.1의 모델 카드는 왼쪽에 모델명·ID·출시일, 같은 행 오른쪽에 입력/출력 가격과 공통 `USD / 1M 토큰` 단위를 표시한다. 입력은 파란색, 출력은 보라색으로 강조하며 미확인·이전 조회값 안내는 유지한다. 820px 이하 화면에서 카드는 한 열로 표시하고 400px 이하에서 여백을 줄인다. 이는 좁은 화면에서의 레이아웃 대응이며 모바일 Chrome에서 확장 설치·실행을 검증했다는 뜻은 아니다.

0.14.0부터 kie.ai 모델 카드에 일반 **입력·출력 USD / 100만 토큰**을 표시한다. 가격에 마우스를 올리면 대응하는 크레딧·정확한 달러 값·조회 시각을 확인한다. 공식 가격표의 환산값을 사용하며 타사 대비 할인율을 한 번 더 곱하지 않는다. 가격표 링크와 **가격 새로고침**을 제공한다. 공개 조회에는 API 키·동의가 필요 없고 사용자 계정에 로그인하지 않는다.

kie.ai 설정 진입·모델 목록 조회 후 가격을 확인하고 화면이 보이는 동안 약 5분마다 갱신한다. 여러 창/연속 클릭의 조회는 합치고 최소 30초 간격으로 제한한다. 숨긴 탭이나 Google 설정 화면에서는 주기 조회를 쉬며 돌아오면 오래된 가격을 갱신한다. **갱신 실패**는 이전 성공 시각과 재확인 필요를 표시한다. 누락·충돌·단위 미확인은 0달러로 간주하지 않는다. 가격 조회 실패 중에도 모델 저장·번역은 가능하다. 공개 가격은 지역·계정별 조건, 캐시·장문 가격을 반영한 청구서가 아니다.

1. 확장 버튼 → **API 설정**에서 Google AI Studio 또는 kie.ai를 선택하고 해당 공급자의 키를 입력한다.
2. **모델 목록 불러오기**를 누른다. 이름/ID 검색과 계열 필터로 모델 카드를 찾는다. 공식 출시일 최근순으로 표시하며 미확인 날짜는 뒤에 둔다.
3. 모델을 선택하고 **선택 모델에 키 저장**을 누른다. 해당 모델에 키를 영구 저장하고 활성화한다.
4. 팝업·설정에서 이번 버전의 원문 전송에 최초 1회 동의한다.
5. 짧고 비민감한 원문으로 번역을 확인한다. 콘텐츠 생성 지원 목록이 텍스트·JSON 출력과 계정별 호출 성공까지 보장하지는 않는다.

재시작 후에는 저장된 모델과 키가 유지된다. **저장된 모델별 API 키**에서 원하는 모델을 고르고 **저장 모델 사용**을 누르면 네트워크 호출 없이 전환한다. 단순히 공급자 선택칸이나 모델 카드만 바꾸면 사용 모델은 변경되지 않는다. 공급자를 바꾸면 입력 중인 키를 지운다. 같은 모델 ID도 Google/kie.ai의 저장 슬롯은 별개다.

kie.ai 지원은 34개 Chat 모델이다. Gemini 2.5 Flash/Pro·3 Flash/Pro·3.1 Pro·3.5/3.6/3.7/3.8 Flash, GPT 5.2/5.4/5.5·5.6 Luna/Terra/Sol·6 Astra, Codex 5/5.1/5.2/5.3/5.4, Claude Haiku 4.5·Sonnet 4.5/4.6/5·Opus 4.5/4.6/4.7/4.8/5·Fable 5, Grok 4.3/4.5/4.6을 지원한다. 공개 공식 문서 목록과 구현한 모델의 교집합을 불러온다. Gemini는 OpenAI 호환 경로를 쓰며 같은 모델의 native 경로를 중복 표시하지 않는다. 문서 조회에는 키를 전송하지 않으며 목록 성공이 키 유효성·잔액·계정 권한을 보장하지 않는다. 검색 결과가 비어도 이미 선택한 모델은 요약에 남으므로 저장 전 선택 요약을 확인한다.

다른 모델에 새 키를 등록하려면 **새 모델 추가**를 고르고 키 입력·조회·저장을 진행한다. 같은 키를 여러 모델에 사용하려는 경우에도 각 모델에 직접 입력해 저장한다. 빈 입력은 대상 모델의 기존 키만 유지하며 다른 모델 키를 복사하지 않는다.

기존 키 교체는 저장 모델을 고른 뒤 새 키를 입력하고 목록을 조회해 해당 모델을 저장한다. **선택 모델 키 삭제**는 선택 슬롯만, **모든 모델 키 삭제**는 전체 슬롯·활성 모델·임시 카탈로그를 제거한다. 키 변경·활성화·삭제 시 진행 중 번역을 취소하므로 본문 패널의 **새 번역**을 누른다.

0.3 이하 세션 전용 키는 자동 영구 이관하지 않는다. 0.4.0 전환 시 한 번 등록해야 하며, 이후 업데이트에는 키가 유지된다. 전송 동의는 새 버전에서 다시 받는다.

## 키 보안

키는 trusted local에 저장하고 화면에 재표시·다른 기기 동기화·내보내기하지 않는다. 저장소는 암호화 금고가 아니므로 공용 기기에서 저장하지 않는다. 노출 시 해당 Google/kie.ai 계정에서 폐기·재발급한 뒤 저장 슬롯을 교체한다. 확장 내 삭제가 공급자 키 폐기를 대신하지 않는다. 자세한 [보안 정책](security.md)을 참고한다.

## 번역과 제한

부분 번역은 **텍스트 선택 → 우클릭 → 선택한 텍스트 번역**으로 즉시 실행한다. 설정·동의가 필요하면 설정 화면에서 처리한 뒤 다시 선택하고 우클릭한다. 본문은 팝업의 **페이지 본문 번역**에서 원문·언어를 확인하고 **번역 시작**을 누른다.

선택 번역은 선택한 원문 위치에 작은 오버레이로 결과를 겹쳐 보여준다. 원문은 변경하지 않으며 스크롤·창 크기 변화에 맞춰 이동한다. 원문이 바뀌거나 제거되면 닫는다. 위치를 확정하지 못하면 전송 없이 재선택을 안내한다. **닫기**로 제거하며 실패한 구간은 오버레이에서 재시도한다. 기본 목표 언어는 한국어이며 본문 설정이 열려 있으면 그 언어를 따른다.

본문은 기존 텍스트 노드 값만 교체해 태그·CSS·링크·이벤트·grid/flex 자식 수를 유지한다. **번역본 ON/OFF**로 번역문과 원문을 추가 호출 없이 전환한다. OFF 중 도착한 결과도 저장만 한다. **패널 닫기** 후에도 표시 상태/결과/진행을 유지하고 작은 **본문 번역 열기** 버튼으로 다시 연다. **새 번역**은 원문을 복원하고 본문·언어·모델을 다시 설정한다. 이후 페이지가 직접 바꾼 노드는 ON/OFF 때 덮어쓰지 않는다. 번역 길이에 따른 줄바꿈/높이 변화까지 고정하지는 않는다.

같은 탭의 마지막 번역 페이지 결과를 임시 보관한다. 새로고침 후 **본문 번역 → 번역 시작**을 누르면 같은 URL·모델 설정 버전·언어·원문 구간은 저장 결과를 사용한다. 달라진 구간만 요청하며 다른 페이지/언어/모델로 번역하면 이전 캐시를 교체한다. 탭 종료·브라우저 재시작·확장 재로드/업데이트에서 삭제한다. 탭별 최대 500구간·원문+번역 1,000,000 코드 단위와 브라우저 전체 session 한도가 있다. 저장 실패 안내가 나오면 현재 문서에서는 유지하되 새로고침 후 추가 호출할 수 있다.

**남은 구간 재시도**에는 동의를 다시 묻지 않는다. 취소해도 이미 전송된 요청의 과금 취소는 보장하지 않는다.

- 본문 수집은 폼·편집·숨김·버튼·iframe·Shadow DOM·canvas를 제외한다. 우클릭 선택은 HTTP(S) 메인 프레임의 비편집 텍스트만 지원한다. Chrome 내부 페이지·PDF는 지원하지 않는다. YouTube 자막은 별도의 팝업 버튼을 사용한다. 이미지는 별도의 이미지 메뉴를 사용한다.
- 동적 본문이나 언어 변경은 새 작업으로 재실행한다.
- 페이지당 60,000 UTF-16 코드 단위·500분할·탐색 텍스트 노드 30,000개. 구간당 2,400, 묶음 요청당 64구간·12,000 코드 단위. 응답 ID로 연결하고 누락·중복·잘못된 ID는 적용하지 않는다.
- 동시 최대 5요청·최근 60초간 최대 60회·세션 입력 200,000 코드 단위. 모든 탭·번역 공급자·이미지·재시도가 호출 한도를 공유하며 키/모델 변경으로 초기화하지 않는다. 본문·부분·자막은 한 차례 최대 5개 묶음 처리 후 5초 대기하고, 로컬 한도에 막히면 자동으로 이어간다.
- 0.17.0 격리 검증: `node tools/chrome-openai-smoke.mjs "C:/Program Files/Google/Chrome/Application/chrome.exe" 0`. 프로젝트 내부의 새 테스트 프로필·확장 복사본·가짜 키/응답만 사용한다. 실제 OpenAI Worker 5개와 본문 400구간의 병렬 적용/휴식/취소를 검사하며 종료 시 전용 Chrome을 닫는다. 결과는 `tools/.tmp/openai-smoke-<timestamp>/result.json`에 저장한다. 제품에는 로컬 서버가 필요 없다.
- 번역 요청 제한은 Google25초/Kie180초, 응답 최대48,000 코드 단위·256KiB. Kie는Chrome116 이상과offscreen 권한으로전용Worker에서통신하고 UI는190초 기다린다. 출력 토큰 상한16,384는Google/Claude 요청에 적용하며 다른Kie 경로의생성토큰상한은 별도로강제하지 않는다.429·503만1초 후 한 번 자동재시도. 모델목록조회18초. 금액단위예산은 아니다.

## 이미지 번역

1. API 설정에서 **이미지 입력과 구조화 응답을 지원하는 Google 모델**을 활성화한다. generateContent 목록에 있다는 이유만으로 모든 모델이 이미지 입력을 지원하는 것은 아니다.
2. 0.10.0 업데이트 최초 1회 텍스트·이미지·자막 전송 동의에 동의한다. 기존 모델별 키는 유지된다.
3. HTTP(S) 페이지의 로드된 이미지를 우클릭 → **이미지 번역**. 기본 한국어 또는 본문 패널의 목표 언어로 즉시 실행한다.
4. 이미지 위 오버레이에서 번역문을 확인한다. **인식한 원문**을 펼쳐 OCR 결과를 확인하고 목표 언어를 바꿔 다시 번역할 수 있다. 문자 없는 이미지는 별도 안내한다.
5. **닫기**는 이미지 결과와 작업 픽셀을 삭제한다. 원본 이미지가 교체/제거되면 자동으로 닫고 늦은 응답을 무시한다. 본문 번역 결과는 그대로 유지한다.

수집·축소·재인코딩은 기기에서 수행하고 인식/번역은 멀티모달 API에서 수행한다. 원본은 수정하지 않는다. 긴 변 최대 2048px·PNG/JPEG 최대 4 MiB·응답 항목당 24,000자·세션 이미지 요청 50회이며 재시도도 포함된다. 실패한 요청이 이미 전송됐다면 과금 취소는 보장하지 않는다.

다른 출처 이미지의 픽셀 읽기가 차단되면 activeTab 화면에서 이미지 영역만 기기 내에서 잘라 처리한다. **전체 이미지가 화면 안에 보이도록 스크롤·축소하고 가리는 패널을 닫은 뒤 재시도**한다. 잘림/가림/변형/복잡한 페이지는 처리할 수 없다고 안내할 수 있다. 캡처는 표시 해상도와 현재 프레임을 사용한다. 전체 화면·이미지 URL은 모델로 보내지 않는다. 프레임·CSS 배경 이미지·Shadow DOM 내부 이미지는 지원하지 않는다. 같은 이미지 URL이 여러 곳에 있어 첫 클릭 대상을 찾지 못하면 해당 이미지를 다시 우클릭한다.

worker가 재시작되어 이미지 작업 토큰이 만료되면 다시 우클릭한다. 이미지는 본문처럼 탭 캐시에 저장하지 않는다. 원문/번역 정확도와 실제 모델 지원은 사용 중인 모델과 이미지 품질에 따라 달라진다.

## 개발 검증

0.16.0 OpenAI 사용: 확장과 페이지 새로고침 → API 설정의 OpenAI (GPT) 선택 → 키 입력 → 모델 목록 불러오기 → 카드 선택 → 모델에 키 저장 → 이번 버전 전송 동의 순서로 설정한다. 본문/부분/이미지/YouTube 자막은 기존 진입 버튼을 사용한다. API 목록에 노출되는 지원 모델만 선택할 수 있고 kie.ai는 계속 비활성 상태다.

OpenAI 개발 검증은 `node tools/chrome-openai-smoke.mjs "C:/Program Files/Google/Chrome/Application/chrome.exe" 45000`으로 실행한다. 허가받은 Chrome 경로와 프로젝트 내부 신규 프로필만 사용하며 외부 네트워크를 가짜 모델 목록/번역 응답으로 대체한다. 실제 전송 모듈의 45초 응답 수신·정리·재생성에 이어 실제 옵션 페이지의 모델 조회·선택·키 저장·재로드와 360/1280px 배치를 확인한다. 결과와 스크린샷은 tools/.tmp 아래에 남기고 브라우저를 종료한다. 실제 API 키를 입력하지 않는다.

Node.js 22 이상에서 `npm test`, `npm run check`, `powershell -NoProfile -ExecutionPolicy RemoteSigned -File tools/verify-harness.ps1`을 실행한다. 가짜 키·모의 API만 사용한다. 0.15.2부터 Kie는 제품에서 사용 중지 상태다. 아래 Kie 전송 smoke는 보존 모듈의 개발 검증일 뿐 제품에서 Kie를 활성화하지 않는다. 기존 Kie 사용자는 확장과 페이지를 새로고침하고 API 설정에서 Google 모델을 직접 저장/활성화한다. Kie 저장 키는 삭제 전용 영역에서 관리하고 사용 통계는 계속 조회한다.

`node tools/browser-fixture.mjs`는 개발용 모의 페이지를 임시 제공한다. 제품 의존성이 아니며 외부 API를 중계하지 않는다.

- `http://127.0.0.1:43188/`: DOM 추출·복원·모의 번역 UI.
- `http://127.0.0.1:43188/options-preview`: 모델별 키·날짜 정렬 설정 UI. 실제 키를 입력하지 않는다. 브라우저 페이지 재로드 유지 테스트에 한해 fixture의 sessionStorage를 local 모형으로 사용한다.

실제 Chrome 설치·재시작·업데이트와 실제 계정의 모델/번역 호출은 별도 검증 대상이다.

Kie 전송의 격리된 실제 Chrome 검증은 다음 명령으로 수행한다. 실행 파일 경로는 사용자에게 허가받은 경로를 사용한다.

```powershell
node tools/chrome-kie-smoke.mjs "C:/Program Files/Google/Chrome/Application/chrome.exe" 45000
```

프로젝트 `tools/.tmp/kie-smoke-*`에 별도 프로필과 공개 모듈 복사본을 만들고 가짜 키·가짜 네트워크 응답만 사용한다. 기존 Chrome 프로필을 사용하지 않는다. 실제 runtime/offscreen/Worker/CSP를 통해 즉시 응답 → 45초 지연 응답 → 문서 재생성을 검사하고 `result.json`을 남긴 뒤 검증 브라우저를 종료한다. 서비스 워커에 디버거를 붙이지 않는다. 테스트 산출물은 구문 검사에서 제외한다. 이 도구는 개발 검증용이며 제품에 서버 의존성을 추가하지 않는다. 0.15.1에서 Chrome 152.0.7977.77로 통과했으며 다른 버전과 실제 공급자·YouTube 전체 경로는 별도 검증 대상이다.

## YouTube 자막 사용 (0.11.3)

1. 확장과 YouTube 페이지를 새로고침한다. 팝업/설정에서 이번 버전의 텍스트·이미지·자막 전송에 최초 1회 동의한다. 기존 모델별 키는 유지한다.
2. www.youtube.com/watch 일반 영상에서 **좋아요·싫어요 묶음 바로 옆의 자막 번역**을 누른다. 홈에서 영상으로 이동해도 자동 표시한다. 좋아요 구조가 다른 경우 같은 영상 작업 영역 끝에 둔다. 키/동의가 빠져 있으면 열린 확장 설정에서 처리한 뒤 다시 누른다. 기존 **확장 버튼 → YouTube 자막 번역** 경로도 유지한다.
3. 제작자 자막 또는 자동 생성 자막과 목표 언어를 목록에서 선택하고 **번역 OFF** 버튼을 눌러 **번역 ON**으로 켠다. 자동자막이 없는 영상은 목록이 나타나지 않을 수 있다.
4. ON 동안 새 자막을 주기적으로 확인하며 현재 시점 이후 미번역 구간부터 묶어 번역한다. 나중에 로드된 구간도 자동 처리한다. 이미 완료한 문장은 재요청하지 않는다. 수집은 완료 후 최소 10초 간격이므로 멀리 탐색한 직후에는 준비 시간이 필요하다. 원하면 영상을 일시정지한 뒤 준비하고 재생한다. 재생·일시정지·배속·탐색 시 현재 video 시간에 맞는 자막만 표시한다.
5. **번역 OFF**는 자동 확인·번역을 중단하고 자막을 숨긴다. 같은 작업에서 ON으로 다시 켜면 완료 문장은 재사용하고 새 구간은 요청한다. **접기**는 패널만 줄이며 ON을 유지한다. 닫기는 패널만 숨기고, 탭 종료/다른 영상 이동은 결과를 삭제하고 자동 번역을 끝낸다. 원문/목표 언어를 변경하면 기존 번역을 비우고 ON 상태를 이어간다.
6. YouTube 전체화면은 플레이어 안에 자막을 유지한다. 광고에서는 숨긴다. 직접 수집 실패 시 정상 플레이어 응답을 받기 위해 YouTube 자막을 켜고 원문 트랙을 변경할 수 있다. 원상복원 여부를 확인할 수 없으면 UI로 알린다. 두 자막이 함께 보이면 YouTube 자막을 끌 수 있다.
7. **자막 세부 설정**을 펼쳐 배경·글자 불투명도(0~100%), 서체(기본/고딕/명조/고정폭), 글씨 크기(12~64px), 세로 위치(위 5%~아래 95%), 가로 정렬을 조절한다. 자막과 미리보기에 즉시 반영하고 이 브라우저에 저장한다. **표시 설정 기본값**으로 복원한다. 위치는 글자가 영상 밖으로 나가지 않도록 제한되며 서체는 기기에 설치된 폰트를 사용한다. 설정 패널은 접어서 영상을 볼 수 있다.

숨겨진 탭·광고 동안에는 새 작업을 잠시 쉬고 복귀하면 계속한다. 네트워크·자막 수집 오류는 ON을 유지하며 최대 60초 간격으로 재시도한다. API 인증/모델 변경/동의/사용 한도 오류는 OFF로 전환하므로 안내를 해결한 뒤 다시 ON으로 켠다. OFF 직전 이미 보낸 요청의 비용은 취소되지 않을 수 있다. ON 상태는 저장하지 않고 새로 열 때 항상 OFF다.

페이지 버튼이 보이지 않으면 확장 관리에서 YouTube 사이트 접근이 허용됐는지 확인하고 YouTube 페이지를 새로고침한다. 임베드에는 표시하지 않으며 플레이어나 작업 버튼 영역의 로드를 기다린다. 새 YouTube 레이아웃에서 영역을 찾지 못하면 기존 확장 버튼으로 연다. 페이지 버튼은 패널을 여는 동작이며, 이미 열린 같은 영상은 ON·언어·번역 결과를 유지한 채 설정만 펼친다.

0.10.2부터 페이지 버튼은 다크/라이트 전환과 인접 버튼 높이·글씨 설정을 따른다. 클릭 또는 Tab으로 선택한 뒤 Enter/Space로 실행한다. 응답이 없으면 20초 후 다시 누를 수 있게 된다. 이번 수정은 확장과 열린 YouTube 페이지를 한 번 새로고침하여 적용한다.

지원 범위: 데스크톱 일반 녹화 영상과 Shorts의 제공되는 제작자/자동자막. 임베드·라이브·자막 없는 영상·PIP 창은 제외한다. 최대 5,000개 이벤트/100,000자/2 MiB이다. 시청 중인 플레이어 내부 정보와 timedtext에 의존하므로 일부 영상/계정/YouTube 변경으로 실패할 수 있다. 0.10.1은 원문 자막 OFF에서도 모듈/트랙 준비를 기다리고 무응답이면 자막 모듈만 한 번 재초기화한다. 최초 목록 읽기에 실패하면 페이지의 **자막 번역** 버튼을 다시 누르거나 **목록 새로고침**을 누른다. ON 중 수집 오류는 자동 재시도하며, 실제 자막 제공 여부와 접근 제한은 여전히 확인해야 한다. 실제 키로 테스트할 때 자막 전송·API 비용이 발생한다.

개발자용 로컬 더미 검증: node tools/browser-fixture.mjs 실행 후 http://127.0.0.1:43188/watch?v=abcdefghijk 를 연다. 이는 개발 테스트 전용이며 제품의 로컬 서버 의존성이 아니다. 실제 공급자/YouTube 호출 없이 기기 생성 무음 미디어, 모의 자막, 지연/실패/탐색/전체화면을 제공한다. ON 후 **후속 자막 구간 로드 → 10초 후속 구간**으로 이동해 자동 번역과 요청 횟수를 확인한다. 표시 설정의 fixture 저장소만 sessionStorage로 모의하며 제품은 trusted local이다.

0.8.1 자막 수정: 직접 URL이 HTTP 200/빈 본문을 반환해도 정상 플레이어 자막 응답으로 재시도한다. 실패 시 CAPTIONS_BRIDGE_FAILED / CAPTIONS_PLAYER_UNAVAILABLE / CAPTIONS_PLAYER_TIMEOUT을 구분한다. 자세한 조치는 [빈 응답 트러블슈팅](../troubleshooting/2026-09-06-youtube-empty-response.md)을 참고한다.

0.11.1에서 **닫기**는 접기 헤더까지 포함한 설정 패널 전체를 숨긴다. 번역 자막은 계속 표시한다. **패널·자막 숨기기**는 둘 다 숨기며 번역 ON/진행/결과는 유지한다. 페이지 **자막 번역** 또는 확장 팝업으로 다시 열면 모두 복원한다. **번역 OFF**는 요청을 멈추고, **닫기**는 번역을 유지한 채 패널만 숨긴다. 같은 영상에서 페이지 버튼은 UI가 보이면 숨기고 숨겨져 있으면 즉시 복원한다. 확장 팝업은 항상 열기로 작동한다. 업데이트 후 확장과 YouTube 페이지를 새로고침한다.

Shorts(`/shorts/영상ID`)는 오른쪽 작업 영역의 **번역** 버튼을 누른다. 목록에서 원문/목표 언어를 고르고 ON으로 켠다. 현재 보이는 세로 영상에 자막을 표시하며 다음 영상으로 이동하면 이전 작업은 종료한다. 새 영상의 버튼을 열고 ON을 켜야 한다. 자막이 제공되지 않는 Shorts는 지원하지 않으며 음성을 자동 인식하지 않는다.

개발용 Shorts 더미: `http://127.0.0.1:43188/shorts/abcdefghijk`. 기존 fixture 실행 중 숨김/복원, 타이밍, 영상 변경, 선행 로드된 숨겨진 video 제외와 분리된 액션바를 검증한다. 개발 서버는 테스트 후 종료한다.

0.11.2: 페이지 자막 번역 버튼을 누를 때 UI가 보이면 숨기고, 숨겨져 있으면 연다. 번역 자막/진행은 유지한다. 확장 팝업의 자막 번역은 항상 열기다. 영상이 화면 밖이면 열 때 해당 영상으로 스크롤한다. 최초 열기 지연 오류는 버튼을 다시 눌러 재시도한다. 업데이트 적용 시 확장과 페이지를 한 번 새로고침한다.

모의 재현: 다음 패널 초기화 1회 실패 → 페이지 번역 버튼 → 실패 안내 → 같은 버튼 재클릭으로 복구한다. watch의 영상 위로 벗어나게 스크롤 → 페이지 버튼으로 UI 위치 복원을 확인한다. 열린 뒤 응답 지연 4초로 메시지 완료 지연도 시험할 수 있다. 모든 입력은 더미이며 실제 공급자 호출은 없다.

0.11.3: 재생 직후 플레이어가 준비 중이면 설정 UI가 화면 오른쪽 위에 나타나고 준비 상태를 표시한다. 플레이어가 안정되면 자동으로 영상에 다시 연결한다. 같은 영상의 교체에서 ON/결과는 유지하며 대기 중에도 UI 토글·닫기·번역 OFF를 사용할 수 있다. 목록은 안정화 후 최대 3회 확인하고 계속 실패하면 안내와 목록 새로고침을 제공한다.

개발 재현: 첫 열기 직후 video 교체 체크 후 페이지 버튼을 클릭한다. 재생 시작 수명 회귀 검사는 교체/분리/0 크기/토글/같은 ID 탐색/다른 ID 정리/video 없는 최초 열기를 자동 확인한다. watch와 Shorts 더미 모두 실제 API를 호출하지 않는다.
